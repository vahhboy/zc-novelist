# 防复发手册 · 落笔守卫

> 这份手册不是写作指南，是**错题本**。
>
> 每一条都对应一类「审校时被挑出来、且大概率会再犯」的错误。
> 条目是通用的：不绑定某一部书的数字和名词，换一部书照样成立。
> 用法不是通读一遍，而是**写完一章之后对着过一遍** —— 写作时记不住，
> 但写完之后回头查，是能抓住的。

配套的机器检查脚本：`scripts/relapse_check.py`（能自动化的部分）。
下面凡标 **[机]** 的条目，脚本已覆盖；标 **[人]** 的必须你自己看。
**脚本过了不等于没事 —— 它只能查形式，查不了因果。**

---

## 〇、三条通则

1. **声明即欠债。** 你写下「一共九个」，就欠了九个，读者会数。写任何数之前，先问「我打算交代完吗」。
2. **写时不算，写完必算。** 时间和数字在写作过程中不管控，只在**写完之后**做一次封闭验算，成本最低、漏网最少。
3. **改稿先看两头哪头牵动少。** 见第四节「刀口选择」——这是全书审查里出现频率最高的一次决策，单独抽出来讲。

## 一、数字与计数

### R-01 **[人]** 声明与列举不符：说 N 个，只列出 N−1 个

- **症状**：正文说「一共九行」，随后逐行列出，读者数下来只有八行。
- **为什么犯**：列举写到后面忘了总数，或中途删过一项没改声明。
- **怎么查**：凡是出现「一共／总共／共 N + 量词」的地方，往下数三十行，把列举项数一遍。
- **自查问句**：这个 N，我在正文里真的数得出来吗？

### R-02 **[机]** 拆分加总不等于总数

- **症状**：「十六个碗，八间屋子分。三间三层／两间两层／三间一个」——加总是 13，不是 16。
- **为什么犯**：改了总数忘了改分布，或改了分布忘了改总数。
- **怎么查**：任何写了分布的地方，把各部分加起来。
- **自查问句**：这些分项加起来，等于我前面给的总数吗？

### R-03 **[人]** 跨章计数链漏了一次动作

- **症状**：甲说「爬了六回，牌上六道」，但逐章核对只有五回刻过——其中有一回一次刻了两道，正文没写。
- **为什么犯**：中间某章漏写了那个动作（常常是"第一次"补刻的那一下）。
- **怎么查**：凡是有计数发生改变的地方，逐章列一份「第几回 → 加了几个」的表，看能不能加够。
- **自查问句**：从 0 到现在的 N，每一步在正文里都有落地吗？头一回要不要补两个？

### R-04 **[机]** 精确值与模糊口语混写

- **症状**：已经确立某处精确是四百，且另有算式（319＋81＝400）闭合；正文却多处写「四百多」。「多」字面是大于。
- **为什么犯**：口语松弛，改动时只替换了部分。
- **怎么查**：精确值一旦成为**已被引用过、且参与过验算**的基准，所有模糊写法（多／来／几／约）都要么统一要么移除。
- **自查问句**：这个数参与过别的算式吗？参与过 → 不许写模糊。

### R-05 **[人]** 比例失衡却没给口径

- **症状**：「那一年转走二十三个」＋「七年一共二十七个」——一批占七年总量的 85%，读者一比就觉得不对。
- **为什么犯**：两个数在不同章、不同语境下各自成立，放一起失衡。
- **怎么查**：把同源的两个量级放一起比。
- **自查问句**：这两个数如果让读者同时看到，比例可解释吗？**不想改数时，加一句口径说明最省。**

### R-06 **[人]** 单位换算没在正文定义，导致判据文件算错十倍

- **症状**：正文「一人十二毫」经验算是 11.93 毫（对）；附录判据却写「一分二／一年一钱四」，差十倍，还被判成"已统一"。
- **为什么犯**：换算基准只在正文某一处出现过一次，判据文件作者自己重算时用了另一套进位。
- **怎么查**：任何带单位的量，先在正文里**明示一次换算**（随口带一句也行），再让所有文件共用它。
- **自查问句**：这套单位，读者能在正文里找到换算依据吗？找不到 → 每次引用都会重算出一个新错。

## 二、时间与天数

### R-07 **[人]** 一个月的偏差，牵动六处

- **症状**：上山月份错一格 → 洗籍日、季节、某角色归来的月份、还有"距今几个月"全部失效。
- **为什么犯**：月份这种**上游锚点**一旦定错，下游全部跟着错，且错得很隐蔽。
- **怎么查**：动任何一个"第几月／第几年"之前，先列下游依赖清单。
- **自查问句**：这个日期被谁引用过？改它要改几处？

### R-08 **[机]** 自述跨度与时间轴算出不符

- **症状**：时间轴算是二个多月，角色自述「上山四个月」；时间轴算九个月，自述「来山上快一年了」。
- **为什么犯**：写的时候凭语感给一个"差不多"，没代进去验算。
- **怎么查**：所有「N 个月／N 年／这些日子」用时间轴减一遍。
- **自查问句**：这个天数减出来是多少？如果不精确，能不能改成不带数的说法？

### R-09 **[人]** 两套日序共用「第 N 天」而无重置标记

- **症状**：前文「第一天／第二天／第三天／第五天」（自甲到场算），后文又出现「第二天早上／第三天早上」（自事故发生算），读者顺着读会顺延误读。
- **为什么犯**：切换参照点时没给读者信号。
- **怎么查**：同一段里出现两组同名的"第 N 天"。
- **自查问句**：这一句"第 N 天"，读者知道是从哪儿数起的吗？**不知道就加重置标记（"出事后的第二天"）。**

### R-10 **[人]** 天数承诺与实际跨度不符，或中间有天窗

- **症状**：某根横木写了「闩了七日」，按时间轴实测是三十五天；两章之间隔了十二天，正文零覆盖，读者问「为什么到这天他才开始数」。
- **为什么犯**：给了一个具体天数显得结实，但没人回头验；或者某章突然让主角开始了一件新事，忘了交代起点。
- **怎么查**：凡是明确写了天数的，代进时间轴；凡是两章之间有空档的，看这个新举动有没有交代过"第一次"。
- **自查问句**：不写天数，用「这些日子」是不是更稳？（通常是的。）

### R-11 **[人]** 时辰与自然现象不符

- **症状**：初七（上弦月，约午夜落下）写到三更（23—01 时）天上有月光。
- **为什么犯**：月光／日头／更鼓是氛围词，写的时候不验算。
- **怎么查**：出现天体与时间的同时出现，代一遍。
- **自查问句**：这个时辰，天上有这个东西吗？

### R-12 **[人]** 周期性日期上的相对写法产生歧义

- **症状**：规则是「每月十六」，正文写「十六的前三天」——十六有好几个，读者不知道是哪个；按最近的那个算，还会章序倒挂。
- **为什么犯**：周期制日期 + 相对偏移 = 歧义 × 候选数。
- **怎么查**：相对偏移（前三天／后天／上周）遇到周期性日期，一律改写具体日期或加所属月。
- **自查问句**：这个"十六"在读者脑子里，唯一吗？

### R-13 **[人]** 台账滞后于正文

- **症状**：台账给某三章分了 20 天，正文实测日差只有 6 天；续写还按台账走 → 全线漂移。
- **为什么犯**：台账是一次性写的，正文在后来的改动中变了。
- **怎么查**：每写完一批，用正文实测回填一次。
- **自查问句**：我上次回填台账，是什么时候？

## 三、排他词与人物口径

### R-14 **[机]** 排他词撞车

- **症状**：刚写「所有人都答不上来」，同章又说「别人都说快了、还早、别问这个」——给了回答就不算答不上来。
- **为什么犯**：「所有／唯一／只有／第一个／从来没有人」是造稀缺的利器，但和前文的松散承认互斥。
- **怎么查**：用排他词**之前**，回前两千字查同类事物是否被承认存在。
- **自查问句**：前文有没有承认过"这类东西不少"？
  → 有 → 换维度排他（人数 → 方向、被动 → 主动），别硬排他。

### R-15 **[人]** 台词挂错人：让角色说出不符合自身立场的评价

- **症状**：把「谁去谁倒霉」挂在某位管事名下——他不会这样自贬自己的地盘。
- **为什么犯**：这句台词是对的，说话的人不对。
- **怎么查**：每句评价性台词，问一句"他会这么说自己的事吗"。
- **自查问句**：换成「这不用他说」之类是不是更稳？

## 四、器物与持有物

### R-16 **[人]** 器物凭空出现

- **症状**：他从怀里「摸出一截炭条」——前文从未交代过他有炭条。
- **为什么犯**：现场需要一个道具就写上去了。
- **怎么查**：凡是从身上、袖里、怀里取出的东西，**必须有前文出处**（谁给的／什么时候捡的）。
- **自查问句**：这东西是从哪儿来的？读者能在前文找到吗？
  → 找不到 → 现场补一句出处（"甘伯给的那小截炭条"）。

### R-17 **[机]** 新道具撞已存在的命名

- **症状**：新写了一个某处的腰牌，也叫「木牌」——和主角那个贯穿全书的木牌重名。
- **为什么犯**：常见词顺手拿来。
- **怎么查**：新增器物前，查一遍已有器物名单。
- **自查问句**：这个词在全书里已经被占了吗？占了 → 换名或加限定（"木牌儿"）。

### R-18 **[人]** 通用名词被临时挪用去指另一类事物

- **症状**：全书十几处「管子」都指铜管，某章突然用「管子」指人。
- **为什么犯**：口语里成立，写进书里就歧义。
- **怎么查**：一个已在书中取得稳定义项的词，不要再给它第二种义项。
- **自查问句**：这个词在读者心里已经定型成什么了？

### R-19 **[人]** 等式的另一半没落地

- **症状**：角色断定"少的那两个都在第五间"（＝两个人），但前文里第五间只伸过一只手、只接过一只碗，第二个无着落 → 后面的「十五个碗，十五只手」直接塌掉。
- **为什么犯**：只写了看得见的那半个等式。
- **怎么查**：凡是推出"这里有 N 个"的，检查有没有 N 个可见证据。
- **自查问句**：我说有两个，读者见过第二个吗？
  → 没见过也能成立，但必须明写成"他没看清"，不能默不作声。

## 五、留白与知情边界

### R-20 **[机]** 破留白：给刻意未命名处命名，或用代词坐实身份

- **症状**：某处全书刻意未命名以保持神秘，某章顺手写出了它的名字；或一直用「那只手」吊着身份，某句写成了「她接过去」。
- **为什么犯**：写久了觉得该说清楚了。
- **怎么查**：维护一张**留白清单**（哪些东西不许点名/不许确认），写之前先看一眼。
- **自查问句**：这个代词／这个名字，是不是比我原计划早半格？

### R-21 **[人]** 把赌注写成了确认

- **症状**：角色赌那可能就是某人（还没证实），下一段的情绪却按"确定了"来写。
- **为什么犯**：作者自己知道答案，写的时候串过去了。
- **怎么查**：区分「他认定的」和「作者认定的」。
- **自查问句**：这段打击力的来源，是"人没了"，还是"他永远无法证认"？两者混写会让重量减半。

### R-22 **[人]** 角色知道了不在场的事

- **症状**：某事件是暗场发生的（角色不在场且不知情），后面他却回想起、或写成亲见。
- **为什么犯**：沿用被推翻的旧稿写法。
- **怎么查**：重排或改动机之后，**逐条检查角色的"所见"有没有跟着失效**。
- **自查问句**：这一刻，他在现场吗？不在 → 他只能"后来才知道"。

## 六、结构与语言层

### R-23 **[机]** 相邻章开头结构雷同

- **症状**：连续两章都是「交了粥 → 廊下遇某人 → 进门」，句式骨架几乎一样。
- **为什么犯**：日常段没有新的进入方式。
- **怎么查**：把连续几章开头各几句抽出来并排看。
- **自查问句**：这三章的开场，能互相区分吗？

### R-24 **[机]** 同章重复叙述

- **症状**：相隔几段的两句话说了同一件事。
- **怎么查**：看相邻段落有没有高度相似的句子。

### R-25 **[机]** 禁用现代词

- **症状**：把现代汉语／说明性词汇写进了非现代语境（意识到、负责、整个过程、反应过来、表情……）。
- **为什么犯**：这些词已经变成书面默认词，写的时候察觉不到。
- **怎么查**：用脚本的词表扫。**词表要按作品换**，脚本自带的是一份起步清单。
- **自查问句**：这个词在设定年代存在吗？

### R-26 **[机]** 中英混排噪音

- **症状**：长文本写入时混进英文单词，甚至整个英文说明段落。
- **为什么犯**：生成式写作的伴生现象。
- **怎么查**：用 `[A-Za-z]{2,}` **全扫**（不要用「汉字夹英文」的窄正则——抓不到空格分隔的情况），再剔除表格行、代码块和文件名。

### R-27 **[机]** 标点体例

- **症状**：疑问句用了问号、叙事里冒出叹号（而作品体例是疑问句一律用句号、零叹号）。
- **怎么查**：体例写进配置，机器扫。

### R-28 **[机]** 叙述者章节元引用

- **症状**：正文里出现「第 X 章」「本章开头」「前文提到」这类跳出故事的指涉。
- **怎么查**：机器扫标题行以外的章节自指。

## 七、加厚

### R-29 **[人]** 加厚 ≠ 注水

- **症状**：为了补字数塞说明、塞回顾、塞重复情绪。
- **怎么查**：补字数只加三类东西 —— **感官与体感**、**次要人物的一两句**、**机制的可见面**（不解说）。
- **自查问句**：补完之后，**重跑一遍互锁数字验算** —— 新写的对话一定会引入新数字，这是加厚最容易埋雷的地方。

## 八、刀口选择：改此处还是改前文

审查记录里出现最多的决策，不是"有没有问题"，而是**"改哪一头"**。通用三步：

1. **把两头都写下来。** 改这个数 → 牵动几处？改那个前提 → 牵动几处？
2. **数清楚，取少的一端。** 经验值：大多数时候是单点修改胜出（一处对六处）。
3. **再看三条否决线**，触线的话，少的一端也不能动：
   - 它是**全书的意象锚点**（一个反复被回想的象征数字／道具）；
   - 它**参与过已闭合的验算**（改它要重算整条算式）；
   - 改它会连带改动没有被指控的地方（无辜的第三者被顺手波及）。

**第四条：改不动的时候，删掉那个承诺，比换个错的数更稳。**
「空了七日」改成「空了这些日子」，既交割了悬念，又永不过期。

## 九、使用节奏

| 时机 | 做什么 |
|---|---|
| **每写完一章** | 跑 `relapse_check.py scan` → 语言层清零 → 过一遍本手册一到七节的 [人] 条目 |
| **改过数字／重排过段落** | 额外跑 `count` 做同槽位数字对照 + 重算相对时间（R-08／R-09） |
| **每写完一批（约十章）** | 跑全套 → 回填台账（R-13）→ 再交给审校团 |
| **收到审校意见** | 落 `notes` → 走 `revision-playbook.md` 的分级与双方案 → 改动前先做刀口选择（第八节） |

**最后一条：** 机器报 0 不能替代你自己读一遍。
所有审查报告里真正致命的那几条，都是**因果层**的 —— 而因果只有通读的人看得见。
