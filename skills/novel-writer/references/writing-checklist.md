# 写作清单 · 写前 / 写中 / 写后

三张清单，**逐项过，不许跳项**；不适用就写"不适用"，不得以沉默代替。
本清单与审校团（阅稿堂）的清单 A/B/C/D 对齐 —— 写作侧先把关，审校侧才不会把时间浪费在低级问题上。

---

## 清单一 · 写前（动笔前必读 `context` 输出）

### 1. 判据锁定
- [ ] 已确认**现行**大纲版本（作废版本不作为判据）
- [ ] 已确认本章对应的卷 / 章 / 节拍
- [ ] 已读 `context --chapter N` 输出的约束包全文

### 2. 接续点
- [ ] 已读上一章结尾，本章开篇能接得上（人物位置、情绪、未解决问题）
- [ ] 已确认本章 story-time 起点 seq，不小于上一章结尾
- [ ] 若本章是回忆/插叙 → 已在登记时加 `--flashback` 并显式标注

### 3. 人物状态
- [ ] 出场人物在本章时点均存活 / 未离场
- [ ] 出场人物的所在地与上一章收尾位置连续（移动要有交代或耗时合理）
- [ ] 角色能说出口的话，都在他的知情边界内

### 4. 伏笔与节奏
- [ ] 本章该埋的伏笔已列入计划
- [ ] 已检查开放伏笔清单，确认没有"已逾期必须回收"的
- [ ] 到期伏笔本章回收的，回收方式与埋设时呼应

### 5. 形式约束
- [ ] 视角、时态与 `style.md` 一致
- [ ] 目标字数范围明确
- [ ] 名词主称呼确认（`glossary.json`）

---

## 清单二 · 写中（落笔时的实时约束）

### 6. 大纲节拍
- [ ] 本章节拍逐条落地，没有整条漏掉
- [ ] 没有**提前兑现**后续章节的关键事件（身份揭晓、道具到手、高潮反转）
- [ ] 没有把关键节拍**延后**挤出本章
- [ ] 没有**变形实现**（换了个方式达成，但效果不等价）

### 7. 时间与逻辑
- [ ] 章内时间推进方向单一（除显式闪回）
- [ ] 相对时标（"三日后""半年过去"）都有明确锚点，不悬空
- [ ] 旅行 / 传讯 / 修炼耗时符合 `worldbuilding.md` 的设定
- [ ] 同一时刻没有同一角色出现在两地

### 8. 视角与信息
- [ ] 限知视角下没有写视角人物看不到 / 听不到的内容
- [ ] 没有让角色知道尚未发生的事件
- [ ] 全章视角人物数量符合 `style.md` 约定（换视角需分隔）

### 9. 声音与语体
- [ ] 角色对白符合其说话特征（见 `style.md` 角色声音表）
- [ ] 没有出现禁用词 / 禁用写法
- [ ] 描写与叙述配比符合语体设定

## 清单三 · 写后（`check` 之前先人工过一遍，机器只查台账）

### 10. 登记
- [ ] `chapter register` 登记了 seq 区间、出场人物、埋/收伏笔
- [ ] `mark-beat` 把本章节拍标为 covered（偏离的标 deviated 并注明性质）
- [ ] 章内发生的状态变化已用 `timeline add --effect` 入账

### 11. 自检
- [ ] 跑 `check --chapter N`，P0 清零
- [ ] 跑 `relapse_check.py` 的 `scan` + `count`，机检项清零（禁用词／噪音／计数链）
- [ ] **人工**过一遍 `relapse-guard.md` 里标 [人] 的条目 —— 因果层机器查不了
- [ ] P1 全部处理或显式记录接受理由
- [ ] 章末钩子与下一章计划开篇连得上

### 12. 偏离处理
- [ ] 任何对大纲的偏离都已 `mark-beat --status deviated`
- [ ] `harmful` 偏离已排进修订计划（见 `revision-playbook.md`）
- [ ] `beneficial` 偏离已同步回 `outline.md`，成为新契约

## 常见翻车点（写作时最容易犯的 8 个）

1. **时间账不算**：连载到后期"三天"和"三个月"混用，读者一算就崩 → 一律用 seq 入账
2. **角色失忆**：前面明确知道的事，后面突然不知道 → 知情边界用 `knows` 记账
3. **战力通胀**：为了过关不断加码，代价不增加 → 力量体系写进 `worldbuilding.md` 的硬约束
4. **伏笔烂尾**：埋了忘收 → 埋的时候就必须填 `due_chapter`
5. **名词漂移**：同一个人三种叫法 → `glossary` 主称呼唯一
6. **视角偷换**：限知视角里突然写别人的心理 → 换章或显式分隔
7. **大纲弃用**：写到后面只顾爽点，大纲形同虚设 → 每章 `mark-beat`
8. **改稿只改正文**：改了剧情不更新台账，检查全失效 → 见修订手册的连锁同步表
