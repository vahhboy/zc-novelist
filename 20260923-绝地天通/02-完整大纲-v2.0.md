## v2.6 追加了什么（作者定案：修内与修外 —— 两派分野）

**仙修内，主角阵营修外。**

| | **修内**（仙 · 仙庭正统） | **修外**（姜烬阵营 · 古法） |
|---|---|---|
| **修的是什么** | **修存量**——往体内存灵气，存得越厚越好 | **修精神（灵魂境界）**——向内求，精神越高，杠杆越长 |
| 怎么用气 | 直接**消耗体内存的那一份**，**用完再吸** | 灵气不进体内，以精神**撬动"精神范围之内"的天地灵气** |
| **威力由什么决定** | **存量 × 法术熟练度 × 肉身承受度**（一击能放多少，看这副身子扛不扛得住） | **精神境界 × 天地灵气浓度**（精神决定能撬多远，浓度决定那一片里有多少可撬） |
| 境界序列 | **练气 → 筑基 → 金丹 → 元婴** | **炼精化气 → 炼气化神** |
| 那口气的下场 | **进身体就出不来。** 死账 | **不进身体，只是借过。** 流水账 |

> **名字最容易误读，口径只有一句**：修"内"修的是**体内的灵气存量**，修"外"修的是**体内的精神境界**——**两派都在向内求，区别只在于那口气象谁借：一个向自己的存量借，一个向天地借。**

> **一条写作纪律：两派阶名不许混写。** 修内是两字格（练气、筑基、金丹、元婴），修外是四字格（炼精化气、炼气化神）。读者一眼能分出这一位是哪家路数。

### 马达模型：大阵起来之后，衰减是渐进的（作者定案）

**不是一刀切。像一台马达：电（灵气）充足时满转速、效果最好；电少了转得慢；电没了才停。**

| | 大阵之前 | 大阵推进中 | 大阵全覆盖 |
|---|---|---|---|
| **修外者** | 灵气充足，**满转速** | **天地灵气被抽得越来越稀薄 → 精神范围内能撬动的越来越少 → 威力一路下降。** 还是那个境界，打出去的东西却变轻了 | 撬不动了，归零 |
| **修内者** | 存量充足，随时可补 | **存量照旧能打（家底还在），但消耗掉的部分补不回来**——外界越稀薄，越难补充 | 存量花完，沦为凡人 |

> **关键差别：修外者是"立刻变慢"，修内者是"慢慢变少"。**
> 修外者当天就觉得不对劲——**还是那一招，打出去却轻了**；
> 修内者要好几千年才觉得不对劲——**还是那一招，打得动，但打一次少一次。**

**这一条定案同时解决了四件悬着的事：**

1. **反向成长终于有了物理原因（且是渐进的）**：姜烬是修外者，靠精神撬动天地间那份灵气。**阵抽得越满，天地灵气越稀薄，他能撬动的就越少——像电压不足的马达，转速一路往下掉，直到归零。** 不是代价，是同一个动作的两面。
2. **仙为什么非要他死**：修内靠存量。大阵一起，体内家底只出不进，且**外界越稀薄越难补充**。**杀掉阵眼＝上行恢复＝又能吸了。** 不是报仇，是**抢路**——他们所有的布局只为一件事：把进货的那条路抢回来。
3. **"杀光仙也没用"落到物理层面**：**仙死，存的那份不还。** 吸进去的气已炼成仙体的一部分，人死则崩解为不能再用的死气——**烧过的炭不能再烧。** 杀了也不还，天地已经空了。
4. **卷六那 3-5 亿年有了依据**：不是他没事干等了几亿年，是**仙的存量要几亿年才花完**。只要还有一个仙体内有余粮，这仗就没结束。

> **最锋利的一句（可直接写进正文）**：**"你们那条路是往身上加，我们这条是往身上减。加到最后，你就是那一颗丹；减到最后，我什么也不是。"**
>
> 这一句的来历：修内的阶名越往后越实（气→基→丹→婴，一路往身上存东西）；修外的阶名越往后越虚（精→气→神→虚→道，身上不长一物，长的是神魂与心境）。**阶名的方向，就是两派的分野。**
>
> 另一版，更贴"精神撬动"：**"你攒的是口袋里的，我攒的是手能伸多远。你把口袋撑大了，我把手伸长了。"**

> **已废弃的一条说法（v2.6 修订中砍掉）**：不再使用"修外者用完散回的气被仙吸走／每调一次气就是替仙备料"。断修外的理由只留一条——**两派共用同一片天地，断仙必断己。**

## v2.2 追加了什么（R-01 作者定案）

**抽取灵气形成大阵 → 大阵挡住血气／信仰／负面情绪被抽取 → 大阵靠继续汲取灵气来维持这道挡。**

一句话：**抽灵气不是为了存，是为了烧。**

| 环节 | 内容 |
|---|---|
| 抽灵气 | 抽的是这一息新生成、还没落到任何人手里的那一份（宇宙自生 ＋ 众生溢出） |
| 成大阵 | 把阵架起来。烧的是**柴**（搜集来的修行资源 ＋ 入阵者主动交出的修为） |
| 挡上行 | 血气（妖）、信仰（佛）、怨念（魔）三样再也抬不起来、走不上去 |
| 维持 | 每息都要重新挡一次，每息都要烧——这一步烧的是**灵气**，永不断供 |

> **两种"柴"不许混写，而且作用不同（v2.3 定案）：**
> - **一次性柴（建阵柴）＝加速器，不是必需品。** 不付，阵照样会成，只是成得慢、要等很久。付了，就是把"很久"压成"来得及"。
> - **持续柴（守阵燃料）＝灵气。** 每息不断，世界自己长出来，永远烧不完。
>
> **这一条定案的意义**：阵法**不需要**任何人死，所以姜烬从头到尾没有抓过一个壮丁。每个人的入阵都是"我想让它快点成"——**自愿由此从道德口号变成了效率问题**，说服从"求你替我去死"变成"我们一起抢时间"。

> **灵气的去处**：当息做功，做完就地散回人间。**没有消失，也没有被藏起来——它被用了一遍，又回到原地。**
> **由此得到全书最狠的对称**：屏障每息烧掉的，正是仙家活命的那一份。**他们烧众生的柴，他烧他们的柴。**

### 上行断绝的直接后果：人活得长了（v2.3 定案）

大阵挡住的不是"修行"这件事，是**三样东西被抽走**。三样东西留在人身上，最直接的后果就是寿命：

| | 无病无灾本该活到 | 被抽的情况下 | 断绝之后 |
|---|---|---|---|
| 普通人 | 七八十 | **四五十就开始死** | 回到七八十 |

> **这是全书最容易写、也最该写的一笔。** 修行昌盛的时代，人活到四五十就没了——没人觉得不对，因为从来就是如此。
> 断绝之后第一批活过六十的老人出现时，人间甚至不知道该拿他们怎么办。
>
> **它同时是"大阵进度条"最好的可见刻度**（见第三节）：不必让人物念数字，写一座村子里老人的年纪就够了。

**连带禁令（写错一处就与世界互相冲突）**：禁写"灵气枯竭／耗尽／归零／不再被抽走"，统一口径只有一句——**不再上行**。完整推演见 `03-世界观架构-v1.2.md` 第七节（已升 v1.3）。

## 一、内核与主题

### 一句话内核

**修行不是天赋，是一条从众生身上接到上界的管子。主角把这根管子掐断了。**

### 主题（全书唯一主题，所有卷必须回扣）

**掠夺的本质从未改变，变的只是手续费。**

荒古要动手抓人 → 远古要建庙守庙 → 上古让别人替自己打 → 宗门纪什么都不用做，人自己排队交上来。越到后面越文明，也越难察觉。

**他想要的世界，是没有剥削与压迫、人人平等的世界。**

不是复仇，不是称王，不是"我要比他们更强"。

## 二、三条世界规则（不定死，中段必崩）

### 规则一：众神为什么不能亲自下界杀死主角？

**业力压制 + 阵营制衡，两条同时成立。**

- **业律**：上界不得直接干涉人道。插手即沾业力，业力消减道行。所以凡有降罚，只能做成天灾的样子：雷劈、地裂、疫病、兽潮。
- **唯一例外：自愿。** 众生自愿献上的东西，业律管不着。这一条例外是整台机器的合规地基。
- **阵营制衡**：仙 / 佛 / 妖 / 魔互相盯着。谁先动手，另外三家就先咬谁。

> 两条合起来的结果：**他们不能直接杀他，但可以让别人去杀他。** 主角的操作空间全在这里。

### 规则二：长生不死的代价

**核心代价：永远不能停。**

他不老、不受寿元限制，所以**连退休的权利都没有**。别人死了是解脱，他活着是职务。

- 只要众生还在活着、宇宙还在生成灵气，他就得一直吸。
- **这不是惩罚，是岗位说明书。**

由此派生的两种表现：

1. **看着所有人死** —— 朋友、爱人、弟子、甚至敌人，一个个老死、病死、战死。
2. **睡着错过** —— 他不是目送的，是睡过去的，醒来发现已经没了，**连告别都没赶上**。

> 第三种表现（v2.0 新增）：**看着他们变。** 见第六节火种设定——他醒来时，认不出人了。

### 规则三：灵气有两个来源，收割路线有四家分工

**灵气来源：**

| 来源 | 特性 | 比喻 |
|---|---|---|
| **宇宙自生** | 量大、稀薄、无印记，只能做基底 | 粗粮 |
| **众生溢出** | 带印记，可直接加工，能养到高阶 | 细粮 |

> 宇宙那份不会停 —— 这是"永远不能停"最硬的物理依据。**即便众生一个不剩，河还在流。**

**四家分工（作者定案）：**

| 家 | 往灵气里加什么 | 要的东西 | **碰不碰人身上的东西** | **在"命如屋"里的角色** | 命门 |
|---|---|---|---|---|---|
| **仙** | 提纯为灵元 | **地**（灵脉、洞天，以及天地间未属任何人的灵气） | **不碰**（v2.5 定案） | **搬走灰浆与备料**——不是构件 | 最慢，也最耐死 |
| **佛** | 信仰 | **信**（要人口，还要人心） | 碰 | **屋脊** | 最先死 |
| **魔** | 怨念（恐惧、绝望、痛苦等负面情绪） | **怕**（要有活人正在受苦） | 碰 | **门窗与火** | 第二死 |
| **妖** | 气血 | **血**（吞血食、带渣） | 碰 | **砖、石、梁、木** | 第三死 |

> **佛要人，魔要人，妖要人。仙不要人——他要人脚下那块地，和天地间一切还没落进谁手里的气。**
> 他不看你一眼。这不代表他干净，**只代表他连"人"这个东西都不必放在眼里。**

> **寿元不归任何一家独有。** 详见下方"命如屋"——把寿命算进妖的那一份，会开出"灭妖即长寿"的捷径，全书根基就没了。

> **记住一句话：四家共用同一份灵气，区别只在往里加了什么。**
> 所以掐断灵气，四条生产线同时停 —— 主角不需要打四场仗。

**大阵怎么同时掐住四条线（v2.2 定案）：**

| 家 | 被掐在哪一环 |
|---|---|
| **妖** | 血气抬不起来——血还在众生和兽身上，只是再也收不走 |
| **佛** | 信仰上不去——**他没有夺走任何人的信仰，他只是让信仰不再被人收走** |
| **魔** | 怨念炼不成刀——从今往后，**害怕就只是害怕** |
| **仙** | 他要提纯的那份原料，正是屏障每息烧掉的那份 |

> **前三样是在"源头"被挡住的，最后一家是在"饭碗"被抢的。** 这也是仙家撑得最久、反扑最狠的原因。

**被挡下来的那些东西，本来是众生自己的（v2.3 定案）：**

> 血气、信仰、怨念，**一样都没被夺走，只是上不去了**；补屋子的料也不再被人整车拉走。
> 于是它们在人身上留了下来——最直接的一条：**人活得长了。**
> 无病无灾本该活到七八十的人，被抽的时候四五十就开始死；上行一断，这个值一路回到七八十。
>
> **修行昌盛的年代，人间普遍活不过五十。这不是天灾，是账单。**

### 命如屋：寿命是怎么被抽短的（v2.4 定案；v2.5 修正仙那一格）

**一个生命不是"有一份叫寿元的东西"，一个生命是一座屋子。**

**寿元不是某个部件，是这座屋子还立得住的年头。** 屋子被抽掉一根梁，年头就短几年；几万年下来，屋子就只剩四五十年的样子。

| 屋子的部分 | 谁在拿 | 拿走了会怎样 |
|---|---|---|
| **气血**（砖、石、梁、木） | **妖** | 骨头先老，伤病好得慢，一场风寒就能带走人 |
| **信仰**（**屋脊**：人靠它知道自己为什么活着） | **佛** | 屋脊一歪，人不是立刻死，是**不想活了**。病了不听劝，也不熬 |
| **怨念／七情六欲**（**门窗与火**：屋子还活着全靠这些在动） | **魔** | 变成四面漏风的壳。人容易受惊，容易吓出病，夜里一惊就过去了 |
| ——以上三样是**构件**；以下这一样不是—— | | |
| **灵气**（**灰浆、泥、备料**：屋子每年靠它补缝，才撑得住年头） | **仙** | **他不拆屋子，他把补屋子的料全搬走了。** 于是小洞补不上，小洞拖成大洞 |

> **三家拆屋，一家断料。**
> 屋脊歪了、门窗没了、砖木被拆，**而补墙的泥早被人整车拉走了**——**屋子漏雨漏风，住在里面的人就病、就惊、就早死。**

**这一条堵死了一个致命漏洞**：旧写法把寿元归进气血，等于开出"灭掉妖就能长寿"的捷径——那样主角只需打一家，全书"必须断绝修行"的根基就塌了。

> **寿元不在任何一家的口袋里，它是四家一起抽出来的结果。**
> 杀光妖，砖木回来了，屋脊还是歪的、门窗还是缺的，**补墙的泥还是没有**——**人照样活不过六十。**

**v2.5 再修一刀：也不能把灵气写成"仙从人身上抽走的构件"。** 一写成那样，仙就与妖佛魔同质；更要命的是**主角修炼照样要耗灵气**，正邪立刻立不住。所以仙这一格必须是**"不碰人，只搬料"**。

#### 主角也用灵气，那他和仙有什么区别？（v2.5 提问，v2.6 定案）

**区别不在"取什么"，在"这口气过不过你的身体"。**

| | **仙（修内）** | **姜烬与他的阵营（修外）** |
|---|---|---|
| 怎么用 | 吸进体内**存起来**——炼成金丹、元婴、仙骨，用时直接消耗，**用完再吸**。威力看**存量、法术熟练度、肉身承受度** | **不存。修的是精神**——以精神**撬动精神范围之内的天地灵气**。威力看**精神境界与灵气浓度** |
| 那口气的下场 | **进了身体，就出不来。** 死账 | **不进身体，只是借过。** 流水账 |
| 对这世界 | **灵气流进仙，是死的**——从此退出循环 | **灵气流过修外者，是活的**——当晚还给了天地 |

> **同一口气：进仙的身体，就再也出不来了；过修外者的手，当晚还给了天地。**

由此得到三条递进的区别：

1. **仙要的是"持有"，所以必须不断扩张**——吸满一处，就得再找下一处。胃口是这条逻辑逼出来的。
2. **修外者要的是"用"，用完就还**——与天地之间是一笔流水账，不是死账。
3. **最重的一条：姜烬最后把自己那份也一起断了。**

> 修为归零之后，他不再调一口。
> **他要的是这世上再没有谁在用——包括他自己。**
>
> **仙要的是自己永远有；他要的是从此谁都没有。**

#### 顺带答了另一个问题：那为什么连修外这条路也要断？（v2.6 重写，最硬的一问）

**不是修外者坏，是只要这条路还在，仙就饿不死。**

- **第一层**：这条路走到尽头就是仙。修外者往上走要的是"源"，而源有限，于是要占、要抢、要定规矩——**两条路的尽头是同一把椅子。换谁坐都一样。**
- **第二层（v2.6 修订，替代原"备料"说法）**：**两派共用同一片天地。** 仙要吸的那一份，和修外者要撬的那一份，是同一片气。**要掐断仙的进货，就得把这片天地抽薄；一薄，修外者也撬不动了。**
  > **所以"能不能只断修内、把修外留着"这一问，答案是不能。** 绝地天通断的是天地之间那条通道，两边都走这条道。
- **第三层（落笔最好用的一层）**：姜烬自己就是修外者，他太清楚这条路的甜头——不用亏本、不用囤积，撬完就还，干净得像什么都没做过。**正因为干净，才最难断。**

> **不是人变坏了，是那个位置把人变成了那样。换谁坐上去都一样。**
>
> 这一句定了卷四那场辩论的输赢：
> **改良派想的是"换个好人坐那个位置"，姜烬想的是"把那个位置拆了"。**

**它同时给卷三末的目标反转补了第二、第三根支柱，而且一根比一根硬：**

> 原来只有一根：*愿力不灭，仙神杀不完，杀一个换一个*。
> 现在多两根：**就算杀得完，一家一家杀也没用**（三家拆屋、一家断料）；**以及换谁坐上去都一样**（两条路的尽头是同一把椅子）。
> 所以姜烬想明白的不是"我杀不完他们"，而是**"我得让这屋子从此不再被拆，也不再有人搬得走它的料。"**

**v2.6 追加一条实证埋线（让"连自己这条路也要断"变成他看见的事实，不是想通的道理）：**

> 卷二或卷三安排一次：**他见过的最强的那位修外前辈，晚年占着一座灵山，不让任何人靠近。**
> 那人没做错任何事——他只是需要一片浓度够的天地，才撬得动他那个境界的东西。
> 这一笔之后，他不再需要任何人说服他——**修外这条路走到高处，要的也是"独占一份天地"。两条路，同一把椅子。**

## 三、反向成长机制（本书命脉）

| 线 | 走向 |
|---|---|
| 修为线 | 卷一至卷三上升 → **卷四达峰后掉头向下** → 卷五暴跌 → 卷六归零 |
| 阵力线 | 卷四之前不存在 → **卷四起持续上升** → 卷五卷六达到维持平衡所需 |

**两条线在卷四交叉。**

### 为什么阵越强，他越弱（v2.6：反向成长终于有了物理原因）

**因为姜烬是修外者。**

他的力量不来自体内——修外者体内永远是空的。他以精神撬动天地间那一份灵气，**能撬多少，取决于那一片里有多少。**

而他立的那道阵，干的恰恰是**把这一息新生成的灵气截下来、拿去挡上行**这一件事。

> **阵抽得越满，天地灵气越稀薄，他精神范围内能撬动的就越少。**
> 像一台电压越来越低的马达：**不是停了，是转得越来越慢。**
> **稀薄到撬不动的那一天，就是他归零之时。**

所以这两条线不是此消彼长的"交换"，是**同一个动作的两面**——他每做成一件事，就同时失去一件东西。

**注意节奏：这是渐进的，不是一刀切。** 他不是某一天突然废了，是**每一天都比昨天轻一点**——还是那一招，打出去的东西一年比一年轻。卷四掉头、卷五暴跌、卷六归零，正好对应马达转速往下掉的三段。

**由此定死两条写作纪律：**

1. **不许写"他先借用一阵，打完再还回去"。** 大阵不储能：截下来的气当息做功、当息散回，他取不出来。
2. **不许写成"他被阵反噬／被谁削弱了"。** 没有人在削弱他。他只是把自己也算进了"从此谁都不许用"里头。

> 一句话：**他不是变弱了。他是这世上第一个把自己写进禁令里的人。**

> **给读者的心理契约**：第一章就要让读者明白"这本书的强，不是境界高"。第一章不说清楚，卷四之后读者会觉得被坑。

### 阵力线的度量（必须可量化，否则后段没有正反馈）

修为往下掉、世界没了修行，**读者需要一个"他确实在赢"的读数**。口径只有一个：

> **屏障覆盖率** —— 全宇宙的上行通道，已经被挡住了几成。

| 阶段 | 读数 | 读者感受 |
|---|---|---|
| 卷四前半 | 一处灵脉 / 一座山门先被掐住 | 第一次看见"掐得住" |
| 卷四中段 | 一域连成片，第一批上行通道永久关闭 | 进度条开始肉眼可见 |
| 卷四后段 | 诸天陆续失联；某一家的第一尊神位断供崩解 | 动真格了 |
| 卷五 | 全覆盖达成 → 平衡 | 代价随之而来 |

**写法要求**：每次读数推进，都要给一个**看得见的现场**——一炷香插下去香灰不烫了、某座庙的钟自己裂了、一个修士照着秘籍练了三年毫无动静。**不要让人物念数字。**

> **v2.3 新增：两个不念数字也能读出来的刻度。**
>
> **其一，人的年纪。** 屏障推进一寸，被抽走的东西就少一分，人就多活几年。
> 卷四写某座村子里"今年有老人活过了五十"——人间以为是自己积德；卷五写第一批活过七十的人，
> 他们的儿女都不认得这么老的爹。**"人活得长了"是全书最朴素、也最有力的胜利读数。**
>
> **其二，成阵的快慢。** 一次性柴不是必需，是加速。所以每次有人主动入阵，读者能看见的不是"阵更强了"，
> 而是**"本来还要等三十年，现在不用了"**——抢下来的时间，就是那一批人的命。

### 战斗形态演化（三次换爽点）

| 卷 | 形态 | 爽点来源 |
|---|---|---|
| 卷一至卷三 | 自己动手打 | 传统爽点：我变强了 |
| 卷四 | 半己半阵 | 转折期，最难写的一段。爽点是"我的棋越下越大" |
| 卷五至卷六 | 打不动了 | **新型爽点："这几招我全见过。"** |

> 第三种爽点的实质：**他活得太久，所以仙神每一次出手他都看过上一次的版本。**
> 他能说出"上一次你们这么干是在某某年，输在哪一步" —— 这是长生者独有的武器，和长生代价正好互为表里。
> **他失去了所有人，也活成了最了解敌人的人。**

## 四、时间轴：前史 × 正传 × 重启（v2.0 重构）

### 4.1 主角必须从宗门纪入场（本次定案，理由必须记住）

旧版让主角从荒古一路活到现代，是**致命错误**。三条理由：

**理由一：对手不够强，故事不成立。**

主角天赋顶尖。若他在收割体系还处于"吞血食"的阶段入场，等于让他带着几万年的时间优势和成长空间，去对付一群还在用石斧的对手。**他当然早就把仙佛妖魔打完了**，后面四卷没有存在理由。

**理由二：他拆的必须是一台成熟的机器，不是草台班子。**

这套机器经过前四个纪元的迭代，已经把所有漏洞都补上了：**每一条规则都是为了防反抗而加的**。它成熟到几乎无懈可击——这才配得上"彻底断绝"这个极端决定。

**理由三：只有"不可动摇"，才能逼出"必须断绝"。**

卷三末的目标反转（杀不完 → 断掉这条路）要有说服力，前提是**所有温和的尝试都已经被前人试过了，并且全部失败**。这些失败记录不在当下，在前史里。

> **一句话：他不是从起点开始追，他是一睁眼就站在了终点前——而终点已经锁死了。**

### 4.2 世界前史四期（不由主角亲历）

| 前史 | 文明形态 | 收割形态 | 换皮的本质 |
|---|---|---|---|
| **血食纪**（荒古） | 部落、祭司、巨兽未绝 | 直接吞气血、生食活人 | 要动手抓人，成本最高 |
| **庙祀纪**（远古） | 第一批庙宇出现 | 立庙收信仰 | 第一次不用动手 |
| **王朝纪**（上古） | 城邦帝国、文字与律法 | 扶植王权，以战争制造恐惧 | 让别人替自己打 |
| **宗门纪 · 初兴** | 修行体系成型、仙门林立 | 把掠夺包装成"修行" | 什么都不用做，人自己排队交 |

> **手续费递减序列。** 宗门纪是巅峰，也是最难察觉的时代。

### 4.3 正传：宗门纪末段的四级跃升（分卷不靠时间，靠尺度）

**六卷不再对应六个纪元。卷一至卷四都在宗门纪末段，用"空间尺度"替代"时间跨度"推进。**

| 卷 | 尺度 | 主角阶段目标 | 时长（建议） | 字数 |
|---|---|---|---|---|
| 卷一 | **一域**（一个仙门及其治下） | 醒来 —— 知道"我们是被养着的" | 数十年 | 15 万 |
| 卷二 | **一界**（一片世界、数域） | 窃火 —— 摸清收割网络 | 数百年 | 20 万 |
| 卷三 | **诸天**（多个世界、触及上界） | 结盟 —— 然后发现杀不完，**目标反转** | 约 2 千年 | 20 万 |
| 卷四 | **全宇** | 以身为阵 —— 绝地天通 | 约 3 千年 | 25 万 |

> **崛起期合计约 1 万年，达到宇宙巅峰。** 这个速度在修行世界里已经快得离谱——别人要十万年。
> 读者不会因为"万年"觉得慢，因为每一卷的世界都在变大。

### 4.4 末法纪与火种纪（主角亲历的下半场）

| 卷 | 内容 | 时长（建议） | 字数 |
|---|---|---|---|
| 卷五 · **末法纪** | 大阵成形、上行断绝、修行者灭绝、灵兽灾变、退化、陨石之劫 | 约 1-2 千年 | 20 万 |
| 卷六 · **火种纪** | 陨石之后**所有人灭绝**，生物圈重启；他教出了一个新物种，一路走到现代 | **见 4.5 / 4.6** | 10-15 万 |

### 4.5 卷六的时间尺度（作者定案：甲）

**地质写实，约 3-5 亿年。**

陨石把生物圈打回接近原点，之后按真正的生命演化节奏重走一遍。

> 选它的理由：这本书的重量本来就应该超出人类尺度——**他对抗的不是四家，是一条每息都在产出的河。**
> 由此也得出全书最重的一个数字：**他不是活了一万年，他活了几亿年。**

**正文里怎么处理这个数字**：建议**不点破**。不给具体年数，只给"很久""记不清是第几次醒来"。年数一旦写出来，读者会开始算；不写，才是敬畏。

### 4.6 卷六的核心设定：他教出来的物种（作者定案）

**陨石之劫引发的环境骤变，把所有人都灭绝了——包括此前留下的火种。**

主角某次沉睡醒来，发现一个人都不剩了。不是没有了某一批人，是**一个都没有**。

> 这是全书最大的一次失重：他守的东西没了。不是为了某个目标去牺牲，是**守的对象消失了他还站在原地**。
> 此时他还没资格绝望——他还得继续站在那儿，因为大阵还在他身上。

**之后：他醒来时所面对的世界，是重新长出来的生命。**

到极晚的时候，星球上演化出了类人生物（猿类）。他做了全书最后的一件事——**教导他们。**

| 项 | 内容 |
|---|---|
| 他教什么 | **火、工具、语言的雏形**。——够了就停 |
| 他不教什么 | 不教修行，不教跪拜，不立规矩 |
| 教到什么程度 | **推一把就走。** 剩下的交给时间和演化。"符合人类进化学说"：人类仍是从猿演化来的，他没有造人，他只是让这一步早来了很久 |
| 然后 | **他必须离开。理由见下。** |

**这一笔是全书最大的一次自我拷问（必须写，否则他的人设崩）：**

第一批学会用火的猿人会怎么看他？——**会跪。**

而他有一条从卷一立到卷六的行为底线：**一旦有人跪他，他就成了他反对的那种东西。**

所以：

> **他教会了火，然后在第二天消失了。**
> 他不是不忍心告别——他是不能留下来听第一声"神"。

**这一幕的三层重量：**

1. **他的人生最后一次重复了同一件事**：他断掉了众生的修行路，也断掉了自己成为神的路。
2. **现代人类是他亲手教出来的，但现代人类不认识他。** 被遗忘这一层代价在这里达到顶点——不是别人忘了他，是**他的学生根本不知道有过老师**。
3. **"人人平等"的最终形态**：他教的是"你们自己可以做"，不是"听我的"。教完就走，是这句承诺唯一的兑现方式。

> 与终章咬合：他今天去救的那个陌生人，是**他的学生第无数代的后人**，而谁都不知道。
> 全书最后一句不需要解释这件事。

### 4.7 前史怎么呈现：三次揭示（重要，决定了前史不是背景板）

前史绝不能用旁白倒述。它必须是**主角亲手挖出来的**，而且每挖一层，都是一次打击。

| 层次 | 呈现方式 | 挖出来的是什么 |
|---|---|---|
| **遗迹层** | 掀开庙祀纪的庙基，下面压着更古老的血食纪祭坛；宗门的山门建在上古的战场之上 | 每一层都比上一层更赤裸 |
| **人物层** | 还活着的"古人"——从庙祀纪活到宗门纪的古妖、仙庭元老。他们本身就是活的遗迹，跟他们对话等于直面前史 | 收割规则的每一次升级，都是为了对付上一次的反抗 |
| **文献层** | 守薪人家族积攒的世代记录（他们的祖先从上古就开始反抗） | **最狠的一层：历代失败者的完整清单** |

> **关键：考古挖出来的不是力量，是绝望。**
> 每一次"原来古人也试过"，都是一次打击。卷三末的目标反转不是想通的，是**被逼出来的**。

> **前史的最重要功能**：它证明这台机器有一个"自我修补"的特性——任何反抗都会被消化、被收编、变成下一次迭代的补丁。
> 守薪人的祖先不是输在弱，是输在**他们的方法被学会了**。这就是为什么必须彻底断绝，而不是改良。

### 4.8 三根钉子（跨阶段不塌的关键）

风险不再是"跨纪元"，而是**每次尺度跃迁都会换一批人**。读者的感情仍然需要着落。

1. **贯穿型角色**：有角色能跨越多个阶段（守薪人、代言人）。
2. **血脉接力**：守薪人一族世代相接。
3. **告别仪式**：每卷末的告别方式保持一致。

### 4.9 告别仪式（每卷固定三拍）

1. 主角替对方完成一件未了的小事（**小事**，不是大事——大事读者无感）。
2. 对方说一句关于下一代的话（把接力棒交出去）。
3. 主角记住这个名字。后文某个阶段，他会再说出这个名字。

> 读者需要可预期的心碎节奏，这比大战更抓人。

## 五、各卷大纲

### 卷一 · 登名（宗门纪末 · 一域）

| 项 | 内容 |
|---|---|
| 核心冲突 | **资质不是恩赐，是入库登记。** 被测出上品资质的孩子，等于被仙门登记在册 |

**目标反转（全书命门，放在卷三末）**

主角原本的目标是"成为最强，杀光仙神"。到卷三末他必须发现这条路走不通。**两根支柱，缺一根反转就软：**

| 支柱 | 内容 |
|---|---|
| **一 · 杀不完** | 只要众生的溢出不灭，仙神就杀不完，杀一个换一个 |
| **二 · 杀光也没用**（v2.4 新增，更硬的一根） | **三家拆屋，一家断料。** 就算一家一家杀得完，补回一样，另外三样照旧在抽——**人照样活不过六十** |
| **三 · 就算换人也一样**（v2.5 新增，v2.6 加宽） | **两条路的尽头，是同一把椅子。** 修内要更多存量，修外要更大源头——走到高处都要占、要抢、要定规矩。不是人坏，是那个位置把人变成那样。**换谁都一样** |

> 第二根支柱的分量在于：第一根说的是"我做不到"，第二根说的是**"就算做到了也没用"**。
> 第三根是压死骆驼的那根：**这条路上不存在一个"好人坐稳"的结局。**
>
> 所以姜烬想明白的不是"我杀不完他们"，而是——**"我得让这屋子从此不再被拆，也不再有人搬得走它的料。"**
>
> 这一句同时定了卷四大师兄那场辩论的输赢：**他要拆的不是某一个人，是那把椅子。**

> 反转的推动力来自前史：**他手上有历代失败者的清单。** 不是他想通了，是他看到了所有想通过这条路的人都死了。
> 另外从卷一起就要埋"杀不尽"的线索（例如某位前辈杀了一位神，第二天那座庙的香火更盛）。
> **v2.4 追加一条埋线**：卷二或卷三安排一次"灭掉某一家的分支"的短期胜利——那一境的妖被清干净了，
> 结果第二年人还是五十不到就死。**这一场失败，是第二根支柱的实证。**

### 卷五里仙的动机（v2.6：不是报仇，是抢路）

**修内者靠存量活着。** 大阵一起，上行断了，他再也吸不到新的一口——从那一刻起，他只剩一件事：**等自己的存粮吃完。**

- 屏障每息烧掉的，正是他赖以提纯的那一份。他不是在跟姜烬怄气，**他是在看着自家米缸见底。**
- **杀掉阵眼＝上行恢复＝又能吸了。** 这是他们唯一的活路。所以末法期间他们所有的布局，本质上只做一件事：**把进货的那条路抢回来。**

> 一句判词：**仙在那几亿年里做的所有事，都是一只存粮见底的动物在找最后一道门。而姜烬站在门里，一步也没让。**

由此顺带解释了另外两条老设定：

| 老设定 | 现在有了动机 |
|---|---|
| 他们不再亲自下界打，只蛊惑 | **他们打不起了。** 每一次出手都是花老本 |
| 越到后来出手间隔越长 | 不是变仁慈，是**花不起**。花掉的那一点永远补不回来，他只能决定这一分该不该花 |

**关键机制：仙神的后手**

**上行一断**，仙神唯一还能起作用的东西，是**事先埋在血肉里的印记**——某些灵兽身上带有仙神留下的烙印。上行既断，烙印发狂，兽失去灵智，只剩杀戮本能。

> **这一手对仙神而言是彻底的自毁**：野兽没有灵智，无法产生可被收割的东西，这等于**亲手把最后一点可收割的东西变成废品**。
> 这不是阴谋，是**泄愤**。仙神明知无用还要做，说明他们已经输了，只剩恨。

**关于第 8 锚点（第一次取火），三条写法纪律：**

1. **不要写成神迹。** 写他手把手教，写那只猿手抖了很多次，写它被烫到缩回去又伸出来。**开化本来就是一个笨拙的过程。**
2. **他走的那天不许有告别。** 他不是不忍心，是不能待到听第一声敬称。
3. **火这一刻从比喻变成实物。** 此前全书所有的"火"都是意象——薪火、火种、烧尽、别让火灭了。在这一幕，它变成了真的火：**他们学会了自己取暖，不再需要从谁那里偷。**

> **第 12 锚点是全书主题的兑现**：几万年的成果，落到一句"神仙在哪"上。

**本卷后段的情感升级（重要）：**

教完之后，这批人就不再是"他守着的东西"，而是**他的学生**。

> 所以卷六后段的蛊惑戏，情感重量全变了：他不再只是尽责，是**有人动了他的学生**。
> 这让百万字最后一段的抵抗重新有了温度——他不是站在那里执行职务，他是在护短。

## 六、火种设定（卷五卷六的底座）

**大阵形成时，姜烬把一部分人留在某一个星球上，他自己也留在那里。**

- **火种是什么**：**一群还没有踏入修行的普通人。** 不是特殊血脉、不是灵种、不是被改造过的存在——就是"还没开始修行"的人，所以灵气断了对他们没有影响。
- **断绝要断得彻底**：守薪人、仙门、灵兽，凡与灵气绑定的存在，一个不留。这条是卷五基调，写的时候不许心软。

### 火种的结局：全灭（作者定案）

**陨石之劫引发的环境骤变，把所有人都灭绝了——包括火种。**

> 这是"断绝要断得彻底"的最后一块拼图：**连他特意留下的人都没能留下。**
> 他守住了这颗星球，没守住上面的任何人。

### 现代人类从哪来：他教出来的

火种全灭之后，这颗星球重新长出了生命。到极晚的时候，演化出了类人生物（猿类）。

**姜烬做了全书最后的一件事：教会他们用火。**

- **第四层代价（被遗忘）的最终形态**：不是别人忘了他，是**他的学生不知道有过老师**。
- 详细写法、他为什么必须离开，见 **4.6**。

> **他的身份在卷六发生了最后一次变化：**
> 卷一至卷四他是反抗者，卷五他是守夜人，卷六前半他是唯一的活人，**卷六后半他成了第一个老师。**
> 而"第一个老师"要做的最后一件事，是**走出去，不让学生回头看见他。**

### 仙神的处境

被挡在界外，不能下界，**只能蛊惑**。

> 注意：火种全灭之后，连可蛊惑的对象都没了。所以卷六前中期，**蛊惑这条线是断的**——这也正是它重新出现时最吓人的时候（当世上又有了能被蛊惑的东西）。

### 每一轮蛊惑的五拍

> 世上生出一代人 → 其中有人被蛊惑 → 主角识破（这招我见过） → 借当世之人布局破坏 → 送走这一批人 → 下一代

与"告别仪式"无缝咬合。轮次三到四轮，每轮换一个当世主角。

**注意时机（v2.1）：火种全灭之后，可蛊惑的对象也一起没了。**

所以蛊惑这条线在卷六中期是**断的**——不是他们不想，是没人可蛊惑。等到新的一批智慧生物起来，这条线才重新接上。

> 这个断口要写清楚。**正是因为空了很久，它重新响起来的那一刻才吓人。**
> 建议的复现顺序：先蛊惑兽（巨兽之世），很久之后才蛊惑人。**隔了这么久才重新下手，正说明他们一直没赢过，只是在等。**

### 蛊惑形态（轮换使用）

| 仙神的蛊惑形态 | 主角的破解 |
|---|---|
| **灵兽发狂（后手，卷五）** | 无法破解，只能熬。兽失灵智即无用，仙神自毁粮仓 |
| 在人心中低语，许诺力量 | 让许诺当场落空 |
| 借兽成患，祸乱部落 | 引兽自困 |
| 立新信仰，重新聚拢愿力 | 让信仰沦为笑柄，香火自断 |
| 扶植被蛊惑者为首领，重建修行 | 让其反噬其主 |
| 附于王者，挑动战争（卷六后段） | 借当世之手拆掉，代价是一城人 |
| 等 —— 等阵眼自己消失 | 他不跟他们等，他只是继续做他一直在做的事 |

> 最后一行是全书终局的底色：**一个在等，一个在干。**

## 七、主角沉睡机制（v2.0 修订）

阵成之后，他无灵气可修、无敌人可打、无事可做，于是**沉睡**。但不能一睡到底——睡到底，后段就没有主角了。

**修订：苏醒节点绑定"世界换了模样"的时刻，全书 8 次。**

> **沉睡不等于脱岗。** 他睡过去时意识沉在大阵里，大阵照样满功率——**他睡着的时候也在守，从来没休息过。**

| 次 | 位置 | 清醒时长 | 醒来时看到的世界 |
|---|---|---|---|
| 1 | 卷五 | 较长 | 灵兽开始发狂，人还在 |
| 2 | 卷五 | 更短 | 野兽已占据大半星球 |
| 3 | **卷五末** | 很短 | **陨石坠落**。他只来得及看见天塌下来的那一半，想出手，发现什么都提不动了 |
| **4** | **卷六开场** | 长 | **一个活人都没有了。** 火种全灭——本书最大的一次失重 |
| 5 | 卷六 | 短 | 海里重新有了活的东西。上一次见到活物是很久以前的事 |
| 6 | 卷六 | 短 | **巨兽之世**。地表被他从没见过的东西占着 |
| **7** | **卷六后段** | 不确定 | **出现了像人的东西。** 他教他们用火，然后走了——详见 4.6 |
| **8（最后）** | 卷六末 | —— | 世上已有城郭与国家。此后他不再睡 |

**五条硬规矩：**

1. **醒来的触发条件必须是"大阵波动"**——不是闹钟，是有什么东西在啃噬大阵。他醒来就得去补，补完再睡。**这让沉睡不是偷懒，是职责。**
2. **每一次醒来，世界都不再是上一次的世界。** 前几次醒来是"人没了"，后面几次是"世界是新的"。
3. **他守的从来不是某一条血脉，是这颗星球还能长出人来这件事。** 火种全灭之后，这句话才真正成立。
4. **第 4 次醒来不给绝望的时间。** 他还没资格崩溃——大阵还在他身上，他得继续站着。这份"没资格难过"比难过本身更难写，也更好。
5. **第 8 次醒来之后，他不再睡了。** 那时候他已是彻底的凡人，凡人要干活、要吃饭、要活下去。

## 八、框架叙事：结尾一次性揭示

### 核心洞察

**现代就是末法时代本身。**

姜烬是阵眼，长生不死，所以他一路活到了今天。我们身处的这个无修行的世界，就是大阵彻底运转后的结果。众神被挡在界外，所以人间再无神仙。

**定案**：全书正文按正常顺序推进，读者以为这是一个正在进行的故事。**到最后一章才揭示：这一切是他临终前的回忆。**

### 代价与收益

- 代价：去掉闪回＝抽掉了贯穿百万字的暗线，中段牵引变弱。
- 收益：恍然大悟的冲击力集中在最后一刻爆发，中段不会有倒叙疲劳。

补牵引靠三样：**大阵进度条 + 每卷告别仪式 + 叙述裂缝。** 三处有一处松弛，中段就会塌。

### 伏笔埋法：叙述裂缝

全书第三人称，但叙述里偶尔冒出一两句**追忆口吻的话**：

> "那一年我十三岁。我见过很多个十三岁的人，只有这一个我记到现在。"

首读时，读者以为这是长生者视角的正常感慨——**因为主角本来就长生，这句话毫无违和**。只有揭示时，这些句子才突然变了意思。

**关键：长生者的设定本身就是最好的保护色。**
**密度**：每卷 2-3 处，全书不超过 15 处。多了会被察觉，少了揭示时没有回扣的抓手。

### 卷首语（叙述裂缝的固定位置）

每卷开头放一段 100-200 字的卷首语，追忆口吻。固定位置形成仪式感。

**核心要求：六段连起来，是一个人从少年到临终的心境史。**

| 卷 | 主题字 | 心境 |
|---|---|---|
| 卷一 | 名 | 少年 · 愤怒 |
| 卷二 | 偷 | 窃火 · 得意 |
| 卷三 | 盟 | 结盟 · 热血 |
| 卷四 | 门 | 断绝 · 决绝 |
| 卷五 | 送 | 送别 · 苍凉 |
| 卷六 | 忘 | 遗忘 · 释然 |

**口吻示范（按作者语感改）：**

> **卷一 · 名**：我十三岁那年，村里办了三天酒席。后来我赴过很多宴，没有一顿是那个味道。那时候我还不懂，被请上桌的，多半是要被端走的。
>
> **卷二 · 偷**：偷东西的人分两种，一种怕被抓，一种怕没人发现。我做了很久的第二种。
>
> **卷三 · 盟**：他们问我凭什么让大家跟着我送死，我说不上来。那天夜里来了三个人，其中一个还牵着孩子。
>
> **卷四 · 门**：门这种东西，关上之前，得先有人站在门里头。我站了很久，久到忘了门外是什么样子。
>
> **卷五 · 送**：后来我睡了很久。醒来的时候，很多事已经不需要我送了——他们走的时候，我不在。
>
> **卷六 · 忘**：我记得的不多了。有些名字要想很久才想得起来，倒是他们的脸，我一直记得。

**卷六这段是全书的钥匙。** 首读以为是长生者的自嘲；揭示后才知道——他不是活太久记不清，他是快死了，正在拼命想。

**三条硬规矩**：
1. 只定情绪，不预告剧情。
2. 全篇不出现现代元素。
3. 六段开头句式不能一样（否则像填空题，机械感会让读者追究"说话的人是谁"）。

### 硬规矩：现代名词不能提前出现

卷六后期文明已发展到现代，但**叙述严格限制在主角认知范围内**——他不认识现代事物：

- 他只会说"会自己跑的铁车""能照亮整个夜的珠子""隔着千里也能听见人说话的小盒子"。
- 读者或许猜得出，但叙述口吻始终是古代的，且主角从不点破。
- **"心电监护""医生""医院"这类词，全书只在终章第一次出现。**

> 附带好处：一个从上古活过来的人看现代社会，这个陌生化视角本身就很有戏。

### 揭示时含义翻转清单（读者的恍然大悟点）

| 元素 | 首读时以为 | 揭示后才知道 |
|---|---|---|
| "我活了很久" | 长生者的自豪 | 一个快死的人的疲惫 |
| 每卷的告别 | 情节需要 | 他在一一清点自己送走的人 |
| 木牌上刻名字 | 记账习惯 | 他在确认自己还没忘掉谁 |
| "后来我再没见过他" | 战乱失散 | 他真的，再也没见过 |
| "我睡了一觉，醒来他们就没了" | 时间跨度大 | 他连告别都没赶上 |
| "醒来发现人都不一样了" | 换了一批人 | **那已经不是他的人了——一个都没有了，后来那些是他教出来的另一批** |
| "守薪人守着火" | 他们会传到现代 | 火留下了，守火的人一个都没剩下 |
| **他去教那只猿用火** | 一个孤独太久的人随手做的好事 | **他知道自己不能留下，还是教了。** 教完就走，是"不想有人跪他"唯一的兑现方式 |
| **现代没人记得他** | 时代太久远，正常遗忘 | **他的学生根本不知道有过老师** |
| 他去救人 | 一个热心肠的路人 | 几万年后他还在做同一件事——**而他要救的这个人，是他学生的第无数代后人** |
| 他醒来不认识手里那块木头 | 失忆后遗症 | **他想起来了，又忘了** |
| 全书为何记得这样细 | 第三人称全知视角 | 将死的人怕自己忘掉，才拼命想起 |

> **整本书，是一个将死之人拼命想要记住自己一生的努力。**

## 九、终章与结局

### 他为什么会躺在病床上

**阵眼只保证"不因寿元耗尽而死"，不保证不病、不伤。**

修为归零后，他就是一具凡人的躯壳。凡人的一切死法他都有份——病、伤、意外、衰竭——**唯独老死不在其中**。

**躺在抢救室的原因（定案）：救人的意外。**

不是病，不是老，不是求死——**他去救一个不认识的人，把自己搭进去了。**

> 价值：他几万年前做的事，和今天做的事，是同一件。**主题在最后一章以行动闭环，一句台词都不需要。**
> **"人人平等"这四个字，靠一次无差别的救人落地**，比任何宣言都硬。

**四条硬规矩：**

1. **绝不写成求死。** 他不可能自杀——自杀等于宣布前面一切白干。**他想活着，因为他还得守着。**
2. **他救的是个不认识的人。** 不需要身份，不需要伏笔，就是一个路人。
3. **真正的张力是"他不能死"。** 他一死，大阵就散，仙神就回来，一切重来一遍。
4. **他不是老死的。** 抢救室里那具身体不该是衰老的。这个反差本身就是揭示的一部分。

### 硬机制：绑定浓度决定大阵功率

**决定大阵功率的不是他醒不醒，是他与这具身体的绑定浓度。**

| 状态 | 绑定 | 大阵功率 | 上行通道（原"灵气水平"口径已废） |
|---|---|---|---|
| 清醒 | 完好 | 满功率，汲取＝维持全覆盖所需 | **全部关闭**，再没有一样东西能走上去 |
| **沉睡** | **完好（意识沉在阵里）** | **满功率** | **全部关闭** |
| **血液被替换／阵纹被切断** | **被稀释或切断** | **衰减，撑不住全覆盖** | **出现破口**：松开的地方重新攒得起气，灵气开始回升 |
| 死亡 | 断裂 | 失效 | 全面复苏 |

> 关键区分：**沉睡是值班，不是脱岗。** 所以他才能睡几亿年而末法时代不崩。

### 抢救室里到底发生了什么（甲 + 乙并用，作者定案）

- **甲**：重伤抢救，**手术切口／清创／植皮切断了他身上的阵纹** → 那段绑定断了。
- **乙**：大量失血 → **大量输血**，血里的阵眼印记被稀释 → 绑定整体变弱。

> **甲的画面**：医生为了止血划开的那一刀，切开的**不只是皮肉**。医生不知道，读者后来才知道。
>
> **乙的主题价值**：他几万年前为陌生人拼命，今天陌生人用血把他救了回来。而救他的方式，正好松动了他守护这个世界的大阵。**世界的血救了他，也放走了他关起来的东西。** 不是背叛，是巧合，代价却是真的。
>
> 附带：他的血能被普通人的血替代，本身就是"人人平等"的实证——他真的只是个人了。

### 设定：他身上刻着大阵的纹

- 成阵时他以身为阵，**阵纹就长在他身上**。平时看不出来，只在受伤、发热、用力时隐约浮现。
- **每一道纹，对应一个主动入阵的人。** 木牌上刻名字，身上刻纹路 —— 同一件事的两种记法：**木牌是他怕忘，身上的纹才是真正的记法。**
- 所以：**纹断了，名字就真的没了。**

> 读者到最后才意识到：**他几万年来一直把所有人带在身上。**

### 失忆的成因（只写现象，不解释）

- **医学层**：心跳停止时间过长，脑缺氧。
- **设定层**：绑定被稀释，记忆跟着流失。身体里属于自己的东西被换掉了，包括他记住的那些人。
- 纹被切断的那几道，对应的人就从记忆里消失了。**他会发现有些地方是空的，但不知道少了什么。**

> 最好的一句台词：**"我好像忘了一件很重要的事，但我想不起来是什么。"**

### 终章三步

1. 古代线收束：大阵达成平衡，世界进入无修行时代。**这一场要写得像"全书结局"。**
2. 硬切：一行之内跳到现代医院。不解释，不铺垫，直接给"心电监护""瞳孔散大"。
3. 回扣：用一两句叙述裂缝的句式收尾，让读者自己把全书翻过来重读一遍。

**第一个画面：人很多，认识他的没有。**

现场很热闹——路人、警察、被救的人（在另一间病房，还不知道救自己的是谁）。然后医生摘下口罩问：**"家属呢？"**

> 没有人回答。

**这一笔比"空无一人"更狠**：围着他的人不少，但没有一个是为他来的。

**最后一个画面：他手里那样东西。**

护士掰开他的手，取出他攥了一路的东西——**一小块碳化的木头**，认不出是什么。那是木牌的残片，上面刻过名字，早看不清了。护士看了眼，放进废弃物袋里。

> **不要解释它是什么。** 让读者自己认出来。

### 结局双版本

#### 版本甲（救回来了）——昏迷、灵气复苏、失忆

| 阶段 | 内容 |
|---|---|
| 抢救成功 | 心跳恢复，转入 ICU。医生说是缺氧时间太长 |
| **昏迷半年至一年** | 阵纹被切断 + 血液被稀释 → 大阵衰减，**灵气在世界各地积累** |
| 苏醒 | 他不记得自己是谁 |
| 出院 | 世界已经开始不一样了——陆续有人"感受到气"了 |

**最狠的一笔：他想起来了，又忘了。**

全书是他拼命记住的一生——每一个名字、每一场告别，他都数了一遍。然后他醒来，全忘了。被世界遗忘还不够，**他自己把自己也忘了**。

**结尾画面**：护士把随身物品还给他——一个小袋子，里面是那块碳化的木头。他看了很久，不认识是什么。**但他没有扔掉。** 全书最后一句可以就停在这里，不加解释。

> **天然开第二部：灵气复苏篇。** 一个失忆的中年男人，在灵气正在回来的世界里，慢慢想起自己是谁——这一次，他是从零开始的凡人。

#### 版本乙（没救回来）——只给一行记录

**不要大张旗鼓，不要悲壮，不要旁白抒情，不要仙神登场。**

> 抢救无效。死亡时间，某年某月某日某时某分。

全书到此为止。

**可选极短余韵（三选一，最多一句）：**

- 同年冬天，某个地方，有人梦见了不该梦见的东西。
- 那份死亡证明后来被归档，编号在某排某列，再没人翻过。
- 那个被救的人活了下来，一辈子不知道救自己的人是谁。

> **建议先发甲、后发乙。** 甲更符合"人人平等"的动机，且能开第二部。乙更冷，适合做真正的终局。

## 十、角色体系

### 三条铁律

1. **每个角色有一个说不出口的秘密**——不是背景，是他自己不愿碰的东西。
2. **每个角色有一个具体的退场**——主角长生，看着他们死。这个退场就是情绪爆点。
3. **每卷核心角色控制在 2-3 人**——多了读者记不住，功能型配角不算。

### 贯穿线一：守薪人（前人反抗失败者的后人）

他们是在姜烬之前反抗仙神、并且**失败了**的那批人留下的后人。

- **"守薪"的实义**：薪是火种。他们守的不是秘密，是上一次反抗没烧完的那点火。
- **v2.0 定位调整**：他们的祖先失败在**前史**（王朝纪或宗门初兴），而不是主角亲历的时代。所以他们等了很久——几千年，久到忘了在等谁。
- **固定台词（定稿）**：**"我们等了很久。久到已经没人记得在等什么了。"**

  > 好处：主语是"我们"不是"我"，写出的是一个**群体**在守；"没人记得在等什么"把绝望推到顶。
  > 变体（可用一次）："我祖父临死前只交代了一句：别让火灭了。他没说等谁。"

- **卷四交接**：他们拿出全部积累——阵法残卷、藏起来的资源、**几代人记下的失败者清单** —— 提供关键助力。那句台词就在这一刻说。
- **成型后灭绝（定案）**：**守薪人一个不留。** 他们知道得太多、修得太深、与灵气绑得太紧。

  > 火传下去了，**守火的人没了**。要写得平静：他们早就知道自己会死，还是把东西交了出来。
  > **灭绝不等于白费**：东西留下来了，进了大阵。人是没了，活是他们干的。

> 关键：他们的祖先是**失败者**。主角不是第一个想做这件事的人，他只是第一个做成的。

### 贯穿线二：仙神的代言人（"薪柴"）

**阶段角色，只出现在大阵形成前的一个时间段内**（主角崛起快，跨纪元宿敌不匹配这个节奏）。

- 仙神不能下界，需要有人替他们在人间办事——**他以为这是信任，其实是消耗。**
- 反转：他发现仙神给他的"赏赐"，与对众生的"收割"是同一套东西。**他不是工具，是燃料。**

> 主题价值：仙神收割众生，连自己人也吃。这是全书主题的最小缩影。

| 弧线 | 内容 |
|---|---|
| 受命 | 被仙神选为代理人，他以为是信任 |
| 与主角对线 | 反复交手，每一次出手都在消耗他 |
| 发现自己被烧 | 察觉"赏赐"与"收割"是同一套 |
| 反水 · 烧尽（卷四） | 用最后一点力量助主角成阵，最后一把火投进阵 |

> **一个与主角对线了千年的人，最后成了阵里的柴。** 这是全书最重的一场奉献戏。
> **反水不能突兀**：从卷一起就铺"燃烧"的痕迹——出手后要歇很久、身上有焦味、从不在同一处停留过久。

### 各卷角色

#### 卷一 · 一域

**核心关系（作者定案）：姜烬与姜萤不是亲兄妹，是同一个村子的孤儿。**

- 两人的父母都消失了——不是病死，是**被带走**。名义上是"征仙役"，实际上去了哪里没人知道。
- 村里每隔几年就有一批人被带走。有补偿，有仪式，大家习以为常。**被仙门看上是一件值得道贺的事。**
- 两人由村里轮流养大，相依为命。

> **这个设定解决三件事：**
> 1. **主角的入场动机落地了**——他去测灵不是为了逆天，是他想去打听父母的下落。**他是半自愿走进去的。**
>    这一笔让"最完美的收割是让被收割的人自己排队"落到了主角本人身上。
> 2. **直接衔接主题剧情**——父母的下落指向第 2 章那场地基戏（见第十二节）。他不是旁观了收割，是**收割已经先吃掉了他的家**。
> 3. **"他是为了一个人"这个起点情绪更干净**——他们没有血缘，只有十几年的相依为命。**不是因为是一家人所以要在乎，是因为在乎所以是一家人。**

|---|---|---|---|
| 姜萤 | 名字里带光，命运是被带走熄灭。她是姜烬唯一的家人 | 全书起点情绪。**他后来去做那件疯狂的事，起点不是天下，是一个人** | 被登记带走。她的下落是卷一至卷三的长线牵引 |
| 失踪的父母 | 不详 | **卷一的长线钩子**：不只是失踪的人，是一把打开第 2 章的钥匙 | 见第十二节 |

| 第一个知情者 | 告诉他"灵气不是天赐的"的人 | 世界观的第一张嘴，说完就死 | 卷一末死于一场"天灾" |

## 十一、牺牲机制（自我奉献的落地写法）

### 核心原则：把"自愿"做成机制条件，不是道德口号

如果阵法可以抓壮丁，主角就是棋手，读者会反感。

设定为：**被迫的愿力会被污染，大阵只接受主动交出修为的人。**

于是"自我奉献"从说教变成了硬门槛。主角不能强迫任何人，只能一个一个去说服。每个入阵者的理由都不同——有人为了孩子，有人恨透了修行，有人只是累了。**这一系列说服场景，是全书最值钱的部分。**

**v2.3 追加：入阵者的付出，是加速，不是必需。**

> 没有他们，阵也会成，只是成得慢。所以主角开口时说的从来不是"我需要你死"，
> 而是**"我们等不起了"**——慢一天，就多一批人被抽到四十岁就死。
>
> 这一条把奉献的意义从"必要的牺牲"改成了**"抢时间"**：
> 每个人交出的不是命，是**本该等下去的那些年里，会死掉的那批人**。
> 它同时堵死了"主角抓壮丁"这个雷——**他从来没资格要求任何人，他只能请求。**

### 四层代价（由外向内递增）

| 层 | 谁 | 代价 | 是否知情 |
|---|---|---|---|
| 一 | 众生 | 溢出被抽走，却不知道自己正在被吃掉 | 不知情 |
| 二 | 入阵者 | 主动交出修为、寿元与记忆 | 知情自愿 |
| 三 | 主角 | 修为归零、永远不能停、目送每一个人老死 | 知情自愿 |
| 四 | 主角 | **被遗忘**——他的学生不知道有过老师 | 知情自愿 |

**第四层最重，且在本轮之后升到了顶点**：不是别人忘了他，是**他亲手教出来的那一批，根本不知道有过他**。




### 主角态度的三段转变（不写这个，主角会变成冷酷棋手）

| 阶段 | 位置 | 态度 | 关键戏 |
|---|---|---|---|
| 拒绝 | 卷二至卷三初 | "我不会让任何人替我去死" | 有人主动求入阵，主角把他赶走 |
| 被迫接受 | 卷三末至卷四 | 不做，就是所有人被吃光 | 第一次开口说服一个人入阵——**写他开口前的沉默，比写说服本身重要** |
| 自己入阵 | 卷四末 | 成为最后一个 | 他终于成了自己曾经拒绝让别人做的事 |

### 入阵者名录

主角每收一个人，把名字刻在木牌上，刻满换一块。

> 这不是死者名单，是**入阵者名单**——每一个名字都是一次自我奉献的凭证。
> 木牌的下落：早被人当柴烧了，或躺在博物馆角落标"用途不明的木质器物"。终章那块碳化的残片就是它的结局。

### 必须保留的反对者视角

**"你凭什么决定断绝修行？对很多人来说，修行是他们活下去的唯一指望。"**

这个质疑不能轻易驳回。主角不是正义的化身，他做了一个可能错误的决定，然后用漫长的时间去承担后果。承载者：**大师兄**。他与主角的辩论是全书思想高潮。

**大师兄这一派的核心主张（v2.5 定案，要写足才是真对手）**：修行本身没错，错的是坐在上面的人。往上爬，坐到那个位置，从里面改——**换个人坐，就好了。**

**姜烬的回应不是"你会失败"，是"你会变成他"：**

> 修得越高，体内越存不住；越存不住，越要一息不停地吸；越要吸，越要占灵脉、定规矩、要人供养。
> **不是你会变坏，是那个位置就是那样。**
>
> **所以我要拆的不是你，也不是他。是那把椅子。**

> 大师兄最后的结局已经定了：**死于体系反噬——改良了一辈子，最后被体系当成异端清除。**
> 这条结局反过来证明了姜烬是对的，但**不要在辩论里让姜烬说赢**。让他输掉那场辩论，然后用大师兄的死来证明。

### 三条禁令

1. **禁止牺牲竞赛**——不要比谁死得惨。每卷只写一两场真正的牺牲戏。
2. **禁止牺牲后立刻变好**——有人入阵后，局面常常更糟。奉献不等于有效。
3. **禁止主角道德完人**——他要有拒绝、有愧疚、有后悔，甚至有几次说服失败。

## 十二、黄金三章设计

### 开篇定案：不要楔子，第一章直接进宗门纪

既然现代只在最后一章出现，开篇就不能有任何现代元素。

**第 1 章就是测灵大典 + 仙门。**（v2.0 改回：旧的"执炬者 + 量灵"作废，那是荒古形态，与主角入场点不符。）

### 第 1 章：资质即原罪

| 项 | 设计 |
|---|---|
| 开场三行 | 立"异常"与"代价"。建议：全村在庆祝，只有姜烬注意到近几年被带走的人，没有一个回来过 |
| 主角处境 | 姜烬与姜萤是孤儿，两人的父母都在某次"征仙役"中被带走。村里每隔几年一批，有补偿，有仪式，大家习以为常 |
| **入场的理由** | **他想去打听父母的下落。** 这是他参加测灵的真正动机——**他是半自愿走进去的** |
| 核心事件 | **测灵大典**。姜烬被测出上品资质，全场道贺，家里摆酒三天 |
| 代价显现 | 当夜，仙门执事上门"登记"——登记的不仅是他，还有他全家。**而他的全家只有姜萤** |
| 章末钩子 | 半夜醒来，姜萤的床空了。**门上钉着一枚仙门的门牌。** |

**第一章必须让读者懂的一句话**：资质不是运气，是被登记入库。

> **最可怕的收割，是让被收割的人自己排队。** 这一句要落在主角本人身上——他不是被抓走的，他自己报了名。
>
> **门牌是全书第一个意象。** 他后来在几千座城门口见过同样的东西。
> 全书最后一次出现这个意象放在终章——他昏迷前最后看见的东西，或者他手里那件没人认得的东西。

### 第 2 章：登记之后，是编号

| 项 | 设计 |
|---|---|
| 核心事件 | **上山。** 他去打听父母的下落，被引到一处所有人都绕着走的地方 |
| **地基戏** | **灵脉不是天然的，是从活物身上长出来的。** 用一场具体的、可视的戏把"灵气从哪来"钉进读者脑子，不靠说明文字。**这一场就是全书的地基戏** |
| **核心画面** | 那里一排一排的栏笼，**里面的人没有名字，只有编号**。有人正在被抽，有人已经抽干了等着处理 |
| 他找到了什么 | **没有找到父母。** 只在某一号栏笼里，看见一件他认得的东西——一双鞋，或者一枚磨旧的物件。**没有答案，只有遗物** |
| 压迫升级 | 姜烬因出身低被山上的人轻贱，第一次被"抽"走自己的东西 |
| 章末钩子 | 他回头看那些编号，第一次意识到：**从登记那一刻起，他们就已经是数字了** |

> **这一章把第一章的"登记"接上了后果。** 登记不是存档，是编号。
>
> **横跨全书的一处伏笔**：他在这里经过某一号栏笼，看见里面的人。卷四他会再遇到一个编号的人——**炉鼎七十三**。
> 读者届时自己会算过来：第 2 章他路过的那一排里，七十三号也许就在那儿。
>
> **父母的下落不在本章了结。** 它是卷一至卷三的一条暗线，可以一直吊着。

### 第 3 章：第一句话

| 项 | 设计 |
|---|---|
| 核心事件 | 第一次反抗（小规模、得手、有代价） |
| 长线牵引 | 说出贯穿全书的种子台词："总有一天，我要让这世上再没有修行这件事。" |
| 注意 | 这句话说出来时必须**是无力的**——他说完就被踩进泥里。**种子要埋在土里，不能立旗** |
| 章末钩子 | 他得到了第一件"能搬空资源"的东西（或第一条线索） |

### 黄金三章硬指标

- 第一章 3000 字内必须出现"代价"
- 三章内必须让读者明白本书的力量体系是**掠夺**
- 三章内必须出现至少一次具体的、可感知的不公（不是背景设定）
- 章末必须留未兑现的牵引

## 十三、待作者确认（其余均已定案）

**本轮新定案（已写入正文，不再列为待确认）：**

- **卷六时间尺度**：甲 —— 地质写实，约 3-5 亿年。正文里建议不点破具体年数。
- **现代人类的来历**：陨石引发的环境骤变**灭绝了所有人**（含火种）；他醒来后教化了演化出来的类人生物。**他没有造人，只是让这一步早来了很久。**
- **姜烬与姜萤不是亲兄妹**，是同一个村子的孤儿，父母被掳走。这个设定用来衔接主题，也让"想打听父母下落"成为他半自愿入场的动机。

**卡着第一章的三项：**

1. **主角姓名** —— 推荐**姜烬**（烬＝烧剩下的东西，与"薪火／薪柴／烧尽／火种"整条意象链咬合）。备选：祝黎、沈薪、顾长明。
2. **姜萤的姓名** —— 推荐**姜萤**（萤火，微小但发光。**她名字里带光，命运是被带走熄灭**）。备选：姜禾。
   > 既然不是亲兄妹，姓氏可另行处理。建议仍作姜萤，并把这笔写清楚：两人登记时随的是村里的姓，**他们本来姓什么已经没人知道，也不重要——重要的是他们是彼此唯一的家人。**
3. **仙门格局** —— 推荐**三宗九门**：仙宗（仙庭系）／梵宗（佛门系）／野宗（妖魔散修的松散联盟，不被承认），九门为三宗之下的具体门派。好处是妖魔有了人间投影，卷三结盟才立得住。备选：一超多强。

**其余待定：**

4. **父母的下落何时了结**：建议一直吊到卷三，甚至永不了结——只留一件遗物。若一定要给答案，最狠的写法是：**他找到了，但他们已经认不出他了。**
5. **陨石之劫要不要给主角戏**：他第三次醒来只来得及看一眼。
   > 本轮之后这件事的重要性下降了——紧接着的"火种全灭"是更大的一刀。**建议不给戏**，留着力气写第 4 次苏醒。
6. **"不甘压迫的物种"包含哪些**：妖、鬼、龙、散修、被献祭的凡人？决定卷三群像量。
7. **阵眼可否移动**：建议"能移动，但离开会在大阵上留下空洞，灵气漏回来"。
8. **火种星球是否唯一**：倾向"唯一"。
9. **书名**：《绝地天通》《末法》《断灵》《我从洪荒活到今天》。

**v2.6 连带出来的三项（修内／修外定案之后才出现的）：**

10. **修外的高阶阶名** —— 建议 **炼神还虚 → 炼虚合道**（作者已定前两阶：炼精化气、炼气化神）。
    > 好处：修内阶名两字格、越往后越实（气→基→丹→婴，往身上加）；修外四字格、越往后越虚（精→气→神→虚→道，往身上减）。**阶名的方向就是两派的分野。**
11. **仙门教的是哪一套** —— 建议：**仙门（三宗九门）教修内**，即仙庭正统；**修外是古法**，只在守薪人与野宗手里流传。
    > 顺带把"野宗"填实为**古法的最后藏身处**；也解释了仙庭为什么要一路淘汰古法——不是它弱，是**修外者体内空空，无处挂编制、收不上税**。
12. **姜烬的修外从哪来** —— 建议甲：守薪人传下的古法。建议乙（更狠）：**他天生存不住气**，气进体内就漏，天生是修外者。
    > 乙的好处：与"反向成长"首尾呼应——**他天生就不是当仙的料，也天生适合干"从此谁都不许用"这件事。**
    > 乙的风险：牵动第 1 章（测灵测的是溢出量，与他存不住并不冲突，但需要在第 1 章埋一句）。

## 十四、风险清单（写作过程中持续自查）

| 风险 | 表现 | 预防 |
|---|---|---|
| **对手太弱**（v2.0 头号风险） | 主角天赋高、成长快，把四家打得像草台班子 | 他入场时机器已成熟。**每一次胜利必须以惨重代价换来，且不能动摇根本** |
| **前四个纪元写成背景板** | 前史沦为设定说明，读者跳过 | 三层揭示（遗迹／人物／文献），每层都要有具体的人和具体的死法 |
| 主角沉睡导致缺席 | 一睡万年，后段主视角消失 | 苏醒绑定生命跃迁点，每次醒来都有具体的事要做；沉睡期间用当世某一家族的视角补位 |
| **卷六写成流水账** | 漫长岁月逐年记录 | 锚点 + 压缩：8-12 个具名场景，其余叙事体带过 |
| 灭绝写法疲劳 | 连写灭绝、灾变、退化、陨石，读者麻木 | 每幕换环境、换敌人、换生存方式；绝望之间必须留一口气的暖场 |
| **断绝不彻底** | 为留角色偷偷给修行者开后门 | 守薪人、仙门、灵兽一个不留。只有"尚未踏入修行的人"能活 |
| **终章写成求死** | 写成想死、等死、暗示自杀 | 他想活着。张力是**"他不能死"** |
| **主角被供奉** | 中段建立新秩序、收弟子、受香火 | 不称王、不立教、不接受供奉 |
| **乙版本写得太满** | 死亡场景渲染、旁白抒情、仙神登场 | 只给一行医院记录 |
| **甲版本失忆写砸** | 失忆写成医学现象，读者觉得狗血 | 只给现象不给解释 |
| 中段塌陷 | 卷二卷三没有新刺激 | **每卷换一次尺度**（一域→一界→诸天→全宇），每卷换一次爽点类型 |
| 主角变遥控棋手 | 修为归零后只布局不露面 | 让他亲自去见当世之人，亲自说服、亲自告别 |
| 代言人反水突兀 | 读者觉得转向太快 | 从卷一起铺"燃烧"的痕迹 |
| 蛊惑轮次重复 | 每轮阴谋长一个样 | 形态轮换，每轮换一个当世主角，控制在三到四轮 |
| 诡计提前泄露 | 中途猜到是回忆，觉得被耍 | 现代元素绝不提前出现；裂缝口吻必须是长生者本人 |
| 揭示力度不足 | 揭示时无感 | 翻转清单至少埋够 5 处，终章逐一回扣 |
| 中段牵引变弱 | 去掉闪回后只剩主线进度 | 大阵进度条 + 告别仪式 + 叙述裂缝 |
| 感情断层 | 跨阶段换人，感情清零 | 三根钉子：贯穿角色、血脉接力、告别仪式 |
| 角色过载 | 每卷角色太多 | 每卷核心 2-3 人，其余纯功能型不命名 |
| 奉献廉价化 | 牺牲写得太轻，角色一笑赴死 | 三条禁令 |
| 主题说教化 | "牺牲小我"变成口号 | 保留反对者视角，且主角无法完美反驳 |
| 收割客体漂移 | 四家分工写成一家一套功法，读者记不住 | **四家共用同一份灵气，区别只在往里加了什么** |
| **忘了灵气有两个来源** | 只写众生那一源，漏掉宇宙源 | 宇宙那份不会停，这是"永远不能停"的硬依据 |
| **卷五写成一场决战** | 四家一起死，场面热闹但主题没落点 | 按次第崩溃写：佛先散 → 魔散 → 妖退化 → 仙最后 |
| **漏写"人间活过来"** | 只写末法衰败，读者看不到成果 | 末法之后必须写：有人酿酒、有人写诗、孩子多了。**修行最昌盛的时代，人间是最死的** |
| **他被崇拜**（本轮新增，头号风险） | 教完火之后写成温情结局，他留下来当首领、当老师 | **他必须走。** 有人跪他的那一刻起，他就成了他反对的东西。这场戏不写，全书人设崩 |
| **第 4 次苏醒写砸** | 火种全灭写成一场哭戏 | **他不哭，他甚至没时间难过** —— 大阵还在他身上，他得继续站着。这份"没资格难过"才是重点 |
| **大阵被写成储能**（v2.2 新增） | 写成"他体内装着全宇宙的灵气""灵气被抽干了" | 大阵不存东西：当息做功、当息散回。写法上只给现象——**河还是那条河，水还是那么多** |
| **口径写成"枯竭/归零"**（v2.2 新增） | 一句"灵气枯竭"就把机制写反 | 全书唯一口径：**不再上行。** 详见 `03` 七节 |
| **一次性柴写成"必需"**（v2.3 新增） | 写成"阵法必须要有人死才能成"，主角变成抓壮丁的 | **它是加速器，不是必需品。** 不付也会成，只是慢。自愿由此是效率问题，不是道德绑架 |
| **忘了写寿命**（v2.3 新增） | 只写修行没了，没写人活得长了，成果落不到人身上 | 修行昌盛的年代人活不过五十；断绝之后回到七八十。**写一座村子里老人的年纪，比念数字有力** |
| **把寿元归给某一家**（v2.4 新增，最危险的一条） | 写成"妖抽走了寿元"，等于开出"灭妖即长寿"的捷径 | **寿元不是部件，是屋子还立得住的年头。** 杀光妖，人照样活不过六十 |
| **把灵气写成仙从人身上抽走的构件**（v2.5 新增，与上条同源） | 一写，仙就与妖佛魔同质；更要命的是主角修炼也耗灵气，正邪立刻立不住 | **三家拆屋，一家断料。** 仙不碰人，只搬走补屋子的料。区别在"取了往哪儿去"，不在"取什么" |
| **把修士写成天生有罪**（v2.5 新增） | 那就成了清算，不是救赎 | **不是人坏，是那个位置把人变成那样。** 断掉的是那条路，不是那些人 |
| **漏掉"他自己那份也断了"这一笔**（v2.5 新增，v2.6 改字） | 主角只断别人不断自己，就成了新的仙 | 修为归零后他不再调一口。**他要的是从此谁都没有——包括他自己** |
| **写"杀了仙，灵气回归天地"**（v2.6 新增，最危险的一条） | 等于开出"杀光仙＝灵气复苏"的捷径，主角只需打一场歼灭战，"必须断绝"的根基立刻塌 | **仙死，存的那份不还。** 吸进去的气已炼成仙体的一部分，人死则崩解为不能再用的死气——**烧过的炭不能再烧** |
| **把修外写成另一种修内**（v2.6 新增） | 修外一旦也能存、也有丹、也有家底，两派分野就废了，"区别在过不过身体"这条主线也一起废了 | **修外不存。** 他体内永远是空的——他攒的是**精神境界**（能撬多远），不是口袋里的存量 |
| **把衰减写成一刀切**（v2.6 新增） | 写成"大阵一起他当场归零"，卷四卷五的坡度全平，后段没有过程可写 | **是渐进的，像马达：** 灵气越稀薄，精神范围内能撬动的越少。修外"立刻变慢"，修内"慢慢变少" |
| **写成"大阵成后他还能撬动灵气"**（v2.6 新增） | 反向成长是命脉。写他还能撬，读者立刻发现阵白立了 | **他要撬的那一份，正是被自己的阵抽薄的那一份** |
| **再用"修外者替仙备料"的旧说法**（v2.6 废弃） | 已被作者砍掉；且它与"大阵不储能""灵气当息散回"不自洽 | 断修外的理由只留一条：**两派共用同一片天地，断仙必断己** |
| **两派阶名混写**（v2.6 新增） | 读者分不清这一位是哪家路数 | 修内是**两字格**（练气、筑基、金丹、元婴）；修外是**四字格**（炼精化气、炼气化神） |
| **教化写成神迹** | 猿类一教就会，从此开化 | 写笨拙：手抖、被烫、缩回去又伸出来。**而且前面必须先有一次失败**（卷第 2 锚点），成功才不廉价 |
| **卷六前期空转** | 火种全灭后一大段没有角色、没有对话 | 用"他试着找一个活人"撑起来——**找的过程就是戏**。无人戏不等于没人味 |
| **现代来得太快** | 教完隔几行就有国家 | 中间隔着极长时间，必须用叙事体把这段压缩交代清楚，否则像过家家 |
| 合规 | 宗教、信仰描写的尺度 | 架空处理。"仙""佛""梵域"等均为架空阵营代称，不指涉现实宗教与在世人物 |
