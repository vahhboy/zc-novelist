# 双轨评分量表 v1.0

阅稿堂统一评分基准。所有分数 0-10 分，允许 .5；必须以文本证据支撑。

## 一、结构：两条轴，各 5 维

```
商业轴（这条稿子，读者肯不肯追下去）
  C1 开篇钩子    Opening Hook
  C2 节奏与密度  Pacing
  C3 爽点回报    Payoff
  C4 期待牵引    Anticipation
  C5 设定可懂度  Setup Clarity

文学轴（这条稿子，值不值得被一读再读）
  L1 人物立体度  Character Depth
  L2 结构编织    Structure
  L3 语言质感    Prose
  L4 冲突张力    Tension
  L5 主题余味    Resonance

合成总分 = 商业轴均分 × Wc + 文学轴均分 × Wl
```

未产生开篇的场景（如评审第 40-45 章）时，**C1 不计入**，商业轴取 C2-C5 均分。

## 二、商业轴评分锚点

### C1 开篇钩子
| 分 | 判定标准 |
|---|---|
| 9-10 | 前三段即抛出一个读者必须知道答案的问题，主角处境自带压力 |
| 7-8 | 有悬念或强冲突，读者愿意再看几章 |
| 5-6 | 交代清楚但平铺直叙，没有必须往下读的理由 |
| 3-4 | 开篇大段环境/设定铺陈，与切身处境无关 |
| 0-2 | 劝退级开头：报菜名式设定、无主角登场、无事件 |

### C2 节奏与密度
| 分 | 判定标准 |
|---|---|
| 9-10 | 每段信息都在推剧情或塑人，无废笔；张弛有明显呼吸感 |
| 7-8 | 偶有拖沓但整体推进感强 |
| 5-6 | 推进尚可，存在可删冗余段落 |
| 3-4 | 大段无效对话/重复心理描写/同类行为复述 |
| 0-2 | 注水：连续多章无实质变化 |

### C3 爽点回报
| 分 | 判定标准 |
|---|---|
| 9-10 | 压抑—爆发结构完整，回报高于付出，看得见铺垫被兑现 |
| 7-8 | 有明确高光且爽点清晰，铺垫厚度略欠 |
| 5-6 | 有爽点但来得太轻易，或兑现力度小于铺垫 |
| 3-4 | 该爽的地方没爽起来（铺垫久、回报小、或被人抢戏） |
| 0-2 | 只有打压没有回报，读者憋屈积累 |

### C4 期待牵引
| 分 | 判定标准 |
|---|---|
| 9-10 | 章末必有钩子，长线目标清晰且具吸引力，短期待与长期待叠加 |
| 7-8 | 有钩子，部分略公式化 |
| 5-6 | 目标存在但不够抓人；部分章节可以随便断在任何位置 |
| 3-4 | 章末平,读者没有"再点一章"的冲动 |
| 0-2 | 目标模糊，读者不知道主角在追什么 |

### C5 设定可懂度
| 分 | 判定标准 |
|---|---|
| 9-10 | 新读者三章内能跟上核心规则，设定随用随出 |
| 7-8 | 规则清晰，局部术语较多但在背景下可推断 |
| 5-6 | 大体能懂，个别概念缺少锚点 |
| 3-4 | 大量术语集中倾倒，需要记忆才能读下去 |
| 0-2 | 设定墙劝退，非硬核读者无法进入 |

## 三、文学轴评分锚点

### L1 人物立体度
| 分 | 判定标准 |
|---|---|
| 9-10 | 角色有独立价值观与自洽的行为逻辑，配角也站得住，看得见变化轨迹 |
| 7-8 | 主角鲜明、动机清晰，配角功能化但可用 |
| 5-6 | 主角有性格但缺内在矛盾，配角多为工具 |
| 3-4 | 人物行为随剧情需要漂移，缺稳定的价值底色 |
| 0-2 | 人物等价于叙述代理人，毫无辨识度 |

### L2 结构编织
| 分 | 判定标准 |
|---|---|
| 9-10 | 多条线索互相关联兑现，伏笔有登记有回收，主次分明 |
| 7-8 | 主线清晰，支线大多有落点 |
| 5-6 | 结构可用，存在支线悬空或回收生硬 |
| 3-4 | 线索散乱，前面提到的东西被遗忘 |
| 0-2 | 章节之间缺乏有机联系，可随意重排 |

### L3 语言质感
| 分 | 判定标准 |
|---|---|
| 9-10 | 有稳定且个人化的语感，句子有音乐性，动词有力 |
| 7-8 | 通顺准确，偶见好句 |
| 5-6 | 合格表达，成语与套话偏多 |
| 3-4 | 错别字、语病、重复用句影响阅读 |
| 0-2 | 语句不成形/ AI 味浓/翻译腔严重 |

### L4 冲突张力
| 分 | 判定标准 |
|---|---|
| 9-10 | 冲突层层升级，多方角逐，角色被迫做两难选择 |
| 7-8 | 对抗明确，有代价有压迫 |
| 5-6 | 有冲突但强度不足，对手偏弱 |
| 3-4 | 冲突被轻易化解，缺乏压榨主角的力量 |
| 0-2 | 一路顺风，没有任何东西真正难住主角 |

### L5 主题余味
| 分 | 判定标准 |
|---|---|
| 9-10 | 故事背后有可以反复讨论的东西，结局或转折具有回响 |
| 7-8 | 有明确的价值表达，读后留有映像 |
| 5-6 | 有主题但未深入，停留在故事层面 |
| 3-4 | 仅袭用类型套路，无个人表达 |
| 0-2 | 价值观混乱或空洞 |

## 四、题材权重表（Wc / Wl）

使用方法：先判断题材，再取权重，并在报告中写明"本次采用 X:Y"。

| 题材类型 | Wc 商业 | Wl 文学 | 说明 |
|---|---|---|---|
| 男频升级流 / 系统流 | 0.70 | 0.30 | 追读为王，爽点密度主导 |
| 都市异能 / 诡异 | 0.60 | 0.40 | 兼顾设定趣味与氛围 |
| 玄幻 / 修仙（长线） | 0.62 | 0.38 | 世界观玩味度高，文学权重略上浮 |
| 女频言情 / 情感向 | 0.50 | 0.50 | 情感浓度与人物关系同等重要 |
| 悬疑 / 推理 | 0.55 | 0.45 | 结构与解谜落地是关键 |
| 历史 / 军事 | 0.45 | 0.55 | 质感与厚重感优先 |
| literary 文学向 / 出版向 | 0.30 | 0.70 | 语言与主题主导 |
| 未知 / 混合题材 | 0.55 | 0.45 | 默认配置 |

> 若作品所在平台或作者明确目标为重追读，可在上述基础上将 Wc 上调 0.05，并在报告中说明理由。

## 五、评级标准

| 合成总分 | 等级 | 含义 |
|---|---|---|
| 9.0 - 10 | S | 罕见的完成度，接近可推爆款 |
| 8.0 - 8.9 | A | 明显优秀，头部水准 |
| 7.0 - 7.9 | B | 良好，具备扎实基础，有明确提升空间 |
| 6.0 - 6.9 | C | 及格，存在结构性问题需处理 |
| 5.0 - 5.9 | D | 危险区，需要较大幅度修改 |
| < 5.0 | E | 建议重写核心部分 |

## 六、追读意愿判定标准

| 判定 | 标准 |
|---|---|
| 继续追 | 合成 ≥7.0 且无致命 P0 问题 |
| 观望 | 合成 6.0-6.9，或存在 1 项 P0 |
| 想弃 | 合成 5.0-5.9，或连续 3 章无明显推进 |
| 已弃 | 合成 <5.0，或遭遇劝退级开篇/致命设定崩塌 |

## 七、禁止事项

- 禁止给出没有原文证据的高分（"整体不错 8 分"不成立）
- 禁止所有读者给出趋同分数——若五类读者分数差不超过 0.5，说明画像没有真正生效，必须重打
- 禁止用"商业 vs 文学"二元词互相指责；两轨是补充关系，不是对立关系
