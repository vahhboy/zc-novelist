# 一致性检查清单 v1.1

四张清单，分别对应大纲对照、设定考据、剧情连贯、时间与逻辑四项作业。**逐项过，不许跳项**；未在本次适用范围内的项要写"不适用"，不得以沉默代替。

> v1.1 新增清单 D（时间与逻辑漏洞）。起因：v1.0 的时间类检查只有 4 个粗项，未要求建立可累加的时间账，导致"一个月/三个月/半年"这类时标并存、以及段落重排后相对时间失效的问题反复漏检。**凡涉及时间的检查，一律以清单 D 为准。**

## 清单 A：大纲对照（novel-outline-checker）

### A1 判定基准
- [ ] 已确认作者指定的**现行**大纲文件路径与版本
- [ ] 已确认不使用标注作废的历史版本作为判据
- [ ] 已确认本次评审覆盖的章/卷范围

### A2 节拍落地
- [ ] 大纲中每一关键事件在正文中找到对应位置（或确认未落地）
- [ ] 检查是否有事件**提前兑现**（尤其是计划靠后的高潮、身份揭晓、重要道具到手）
- [ ] 检查是否有事件**延后**（关键节拍被挤出本次范围）
- [ ] 检查是否有关键事件**变形实现**（换了一种方式达成，效果是否等价）

### A3 结构顺序
- [ ] 卷/单元的先后顺序是否符合大纲
- [ ] 关键转折点的位置是否与设计一致（如"中点反转"出现在计划位置附近）
- [ ] 是否存在整段支线被跳过或长期悬空

### A4 角色

- [ ] 每个重要角色的**首次登场时机**是否符合安排
- [ ] 是否存在角色应下线却持续在场，或应回归却迟迟不出现
- [ ] 主角戏份占比是否被支线或配角挤占

### A5 伏笔埋点
- [ ] 大纲要求在本阶段埋下的伏笔是否真的埋了
- [ ] 埋设强度是否足够（是否会被读者忽略）
- [ ] 埋设位置是否过早暴露意图

### A6 偏离性质判定
- [ ] 每条偏离已判定：有害 / 中性 / 有益
- [ ] 有益偏离已建议吸收进大纲
- [ ] 有害偏离已给出回改方案

## 清单 B：设定考据（novel-canon-keeper）

### B1 世界规则
- [ ] 核心规则（修炼/技术/禁忌/代价）在本次范围内**从未被无故无视**
- [ ] 若出现例外，是否给出了解释（升级/特例/代价）
- [ ] 力量的使用是否始终付出对价

### B2 时间与数值
- [ ] 章节间的相对时间（"三日后""一个月前"）累加是否自洽
- [ ] 角色年龄、年份、节日、节气是否一致
- [ ] 距离/行程/速度是否合理
- [ ] 修为等级、境界、排名前后一致
- [ ] 资源、金钱、人数等到账计算是否自洽

### B3 名词统一
- [ ] 人名（含同音误写、异体字、绰号/本名混用）
- [ ] 地名、宗门名、势力名
- [ ] 功法/武器/器物名
- [ ] 专有名词首次出现是否给了定义

### B4 人物属性
- [ ] 外貌特征（发色、瞳色、疤、身高、惯用手）
- [ ] 性格底色与行为是否漂移
- [ ] 口头禅、称谓、敬语体系是否一致
- [ ] 亲缘/师承/阵营关系是否前后一致
- [ ] 伤势、残疾、疾病是否被无解释地治愈或遗忘
- [ ] 持有物、随身道具是否连续

### B5 战力与出场
- [ ] 越级胜利是否给了足够铺垫或代价
- [ ] 同类敌人强度是否前后失衡
- [ ] 是否存在无解释的能力突破
- [ ] 龙套强度是否随主角提升而无上限通胀

### B6 取证要求
- [ ] 每条矛盾都有**两处以上**原文引用
- [ ] 只找到一处出处的已归入"待核实"
- [ ] 严重度已标注：致命 / 明显 / 细微

## 清单 C：剧情连贯（novel-plot-tracker）

### C1 因果链
- [ ] 每个重要结果都有明确成因
- [ ] 角色的"知情"都有获得渠道（亲眼/听闻/推断——**且该渠道在前文存在**）
- [ ] 角色的"赶到"有空间与时间可行性
- [ ] 巧合的使用是否有够多的铺垫

### C2 动机
- [ ] 每个重要行动都有驱动力（欲望/压力/代价）
- [ ] 检查是否存在角色为剧情需要而降智
- [ ] 反派的行动是否源于其自身目标，而非纯为推动主角
- [ ] 缺少动机的地方已建议补哪种补法（补台词/补胁迫/补收益）

### C3 伏笔台账
- [ ] 已建立/更新台账：编号、埋设位置、内容、状态
- [ ] 已标注每条伏笔的**悬置章数**（量化，不用"很久"）
- [ ] 已识别逾期未回收项（一般悬置超过 30-40 章视为高风险）
- [ ] 已区分"读者还惦记"与"读者已遗忘"

### C4 悬念管理
- [ ] 列出全部未解问题及其悬置时长
- [ ] 判定每个悬念：健康（有期待）/ 失信（拖太久）/ 失效（读者已猜到结果却迟迟不兑现）
- [ ] 检查答案给出时机：过早失去张力、过晚失去耐心

### C5 知情边界（POV）
- [ ] 每个视角下角色只知道他应知道的
- [ ] 已揭示的事实没有被角色继续无视
- [ ] 同一事件的多视角叙述是否一致（非矛盾）

### C6 台账延续
- [ ] 若有历史台账，已承接并更新而非重建
- [ ] 完整台账已随报告回传给主理人

## 清单 D：时间与逻辑（novel-logic-auditor）

> 本清单是**时间与逻辑漏洞的专项检查**，优先级高于清单 B2 的粗检项。凡是"算不算得过来"的问题，一律走这里。

### D1 时间账（必做，缺表即视为未查）
- [ ] 已建立逐章**时间轴表**：章 / 绝对时刻 / 本章相对时间锚点 / 本章跨度 / 全书累计
- [ ] 全部相对时间（"过三日""一个月后""去年今日"）已做**加法**，总和与文内自述的总时长核对过
- [ ] 若段落顺序被重排过，"明天""三天后""去年"等相对时间的**参照点已全部重算**
- [ ] 时辰、季节、节气、月相、昼夜长短、节日与场景描写一致（夜里有没有月光、冬天会不会出汗）
- [ ] 本章新出现的总时长自述（如"半年后""三年前"）与逐章累加结果一致
- [ ] 若工作区已有本项目的跨章时间台账，已**承接更新**而非重建

### D2 在场性与行程
- [ ] 同一时刻每个人物所在位置已列出
- [ ] 场景切换的**路程与耗时**是否够（上一场到这一场来得及吗）
- [ ] 谁能在场、谁能听见看见；无"不可能在场却在场"的人
- [ ] 两条线并行时，各自时刻已对齐（A 线的"当天"＝ B 线的哪一天）
- [ ] 传信/消息传递的耗时与后续事件的时点不矛盾

### D3 状态连续性
- [ ] 伤势、疾病、中毒、疲劳：何时受、多久能好、本章是否还在
- [ ] 持有物：何时得、何时交出、何时丢失；清点场景的件数与前文一致
- [ ] 地点、天气、光照、季节前后一致
- [ ] 环境破坏（烧掉的、塌了的、修好的）前后一致
- [ ] 人物的生死、被囚、离队、归队状态前后一致

### D4 因果与时序倒挂
- [ ] 无"结果出现在原因之前"（先写某人已知某事，后才写他得知）
- [ ] 动机与情报的**交付时点早于**依赖它的行动
- [ ] 伏笔的"埋"早于"收"，揭示不早于铺垫
- [ ] 事件先后与文中"此前/之后/与此同时"的表述一致

### D5 排他词与计数
- [ ] 「唯一」「只有」「第一个」「从不」「全都」「再没有」——用之前已查前文是否承认过同类事物存在
- [ ] 编号、刻痕道数、物品件数、人数、钱数、配额等**计数项全局一致**
- [ ] 同一事物未被赋予两个不同的量（如三页与四页、五十八号与五十九号）
- [ ] 改动计数后已**全局替换**，不是只改一处

### D6 新设定回头咬旧文
- [ ] 本章新立的规则/设定，已回头把全书相关人名、事件、数字筛过一遍
- [ ] 旧稿中被当作"先例"引用的人物与事件，未被新规则无意作废

### D7 取证与定级
- [ ] 每条问题走完**四问**：前文断言 / 本章断言 / 冲突点 / 修法
- [ ] 只有一处出处的已归入「待核实」，未伪装成确定结论
- [ ] 已定级：致命 / 明显 / 细微
- [ ] 修法已给"**改前文** vs **改此处**"两个方案及各自代价

## 通用要求

- 完成调查后，每个清单组的每个适用项都要有明确的"通过/发现问题/不适用"结论
- **没有证据的判断不得写入正式结论**
- 三条清单之间可能有交叉发现：发现疑似属于其他组的问题时，标注后交给主理人转派，不要越权裁定
