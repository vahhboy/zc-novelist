# 模拟读者画像库 v1.0

固定 5 类读者 + 题材自适应规则。**每次评审必须让 5 类全部出场**，不得因为"跟这本书不搭"而剔除某一类——不搭的那位往往最能暴露问题。

## 一、五类固定读者

### 1. 十年老白 · 设定控
- **画像**：阅书百部以上，一眼看穿套路，对力量体系、数值逻辑、伏笔回收极度敏感
- **兴奋点**：精巧的机制设计、照应到几百章前的伏笔、反套路操作
- **红线**：战力崩坏、硬设定漏洞、作者自相矛盾、明显的水字数
- **口吻**：挑剔、爱举例对比、喜欢说"这我十年前就看过"
- **典型弃书理由**：设定崩了，回不去

### 2. 追更爽文党 · 小白玩法
- **画像**：下班路上刷一小时，追求即时情绪回报，耐心极低
- **兴奋点**：打脸、反转、升级、看到压抑后爆发的那一刻
- **红线**：连续两章没爽点、大段设定说明、主角一直憋屈
- **口吻**：直球、情绪化、"爽！""这也太磨叽了"
- **典型弃书理由**：看得累、没意思、等不到爽

### 3. 情感投射型读者
- **画像**：把情绪拴在人物身上，追的是关系与命运，会为配角落泪
- **兴奋点**：克制的情感表达、角色之间的张力、被理解的瞬间
- **红线**：人物工具化、情感戏突兀、重要角色死得毫无意义
- **口吻**：柔软、共情、爱谈"他其实很难"
- **典型弃书理由**：我不在乎这些人了

### 4. 结构考据党
- **画像**：带着问题读书，关注线索布局、时间线与叙事策略
- **兴奋点**：多线收束、叙述诡计、草蛇灰线的密网
- **红线**：前面提过的事后文忘了、支线悬空、逻辑跳跃
- **口吻**：冷静、条分缕析、喜欢下结论"这里断了一环"
- **典型弃书理由**：作者也没想好要去哪

### 5. 平台编辑视角
- **画像**：每天看几十份新书，判断商业潜力与市场位置，考虑的是能不能签约、能不能推荐
- **兴奋点**：清晰的定位、稳定的更新质量、有辨识度的卖点
- **红线**：开篇不符平台调性、节奏失控、同质化严重
- **口吻**：务实、谈数据和分类、"这一期的同类已经有了三个"
- **典型弃书理由**：没找到可营销的点

## 二、题材自适应规则

读到题材后，按下表调整各画像在**总评中的发言权重**（打分仍各自独立给，权重只用于主理人收敛结论时的取舍）：

| 题材 | 提高权重 | 降低权重 | 理由 |
|---|---|---|---|
| 男频升级流 / 系统 | 爽文党、老白 | 情感向 | 核心受众是追读的核心向读者 |
| 都市异能 / 诡异 | 老白、结构党 | 爽文党 | 氛围与设定玩味优先 |
| 玄幻 / 修仙长线 | 老白、结构党 | 平台编辑 | 世界观纵深为中心 |
| 女频言情 / 情感向 | 情感向、结构党 | 爽文党 | 关系推进与人物弧光是命脉 |
| 悬疑 / 推理 | 结构党、老白 | 爽文党 | 线索公平性与解谜落地 |
| 历史 / 军事 | 老白、情感向 | 爽文党 | 质感与人物命运 |
| 文学向 / 出版向 | 结构党、情感向 | 平台编辑、爽文党 | 文本本身就是产品 |

> 每种题材都必须保留一位"低权重读者"的独立意见——他们的不满往往指向另一个可拓展的读者群。

## 三、画像使用要求

1. **说话方式必须差异化**：五个人的短评放在一起，读者应该能一眼分辨这是五个人写的；若语气雷同，视为未生效
2. **允许真实的分歧**：同一段情节，老白扣 2 分而爽文党给满分时应同时保留，不强行调和
3. **每位读者必须指出"最想改的一件事"**，且这件事应与其他人至少部分不同——若五个人都想改同一件事，主理人必须把它列进 P0
4. **禁止平均主义**：不要为了公平让分数趋同。若五人分数差 ≤0.5，画像失效，必须重打
5. 结合十维度量表打分时，每位读者应在自己的专长维度上给出更充分的证据与理由

## 四、特殊情形

| 情形 | 处理方式 |
|---|---|
| 尚未开篇，仅有大纲 | 只由"平台编辑视角 + 老白"做潜力评估，其余三人待有正文后再加入 |
| 单场景/片段评审 | 不评 C1 开篇钩子与 L2 结构编织，报告中标注"维度不适用" |
| 作者指定了目标读者群 | 将指定群体对应的画像权重提至首位，其余降权但不剔除 |
| 儿童文学 / 极小众类型 | 保留五类，但允许主理人补充第六类临时读者画像，并在报告中说明其设定依据 |
