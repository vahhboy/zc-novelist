# 文字与节奏检查清单 v1.0

> 专用席位：`novel-prose-analyst`（薛斟句｜文字与节奏分析师）
> 定位：**微观取证层**——何知味负责把 C1/C2/C3 打成分数，你负责指出**具体哪一句不行、为什么不行、往哪个方向改**；方可行拿到你的诊断才动手改写。
> 与其他清单的关系：本清单不判一致性（那是 A–D 的事），不判故事走向，只判**句子和段落层面的阅读体验**。

---

## 清单 E：文字与节奏（novel-prose-analyst）

### E1 开篇钩子（必查）

**查什么**：每章**前 300 字**；全书第一章延伸到前 1000 字。

**判定点**：
- 第一段有没有给出「值得继续读的理由」（冲突 / 悬念 / 反常 / 利害）
- 是否用大段环境描写或背景交代开场（高频病：开篇即设定倾倒）
- 视角人物的**当下目标或麻烦**是否在前 300 字内可见
- 全书第一章额外查：主角出场是否够早、金手指/核心悬念是否在 1000 字内有暗示

**定级**：严重 = 开篇无钩子且前 300 字无任何冲突信号；明显 = 有钩子但被 2 段以上无关信息稀释；轻微 = 钩子偏弱但可接受。

### E2 章节结尾卡点

**查什么**：每章**最后 200 字**。

**判定点**：
- 断章位置是否落在悬念点 / 转折点 / 情绪峰值上
- 是否在收尾处把本章悬念**提前解开**（高频病：结尾总结陈词，把余味说破）
- 是否用「欲知后事」式硬钩（网络语境可用，但连续多章滥用会疲劳）
- 连续多章横向看：断章类型是否重复（连续三章都「危机断」会钝化）

**定级**：严重 = 连续多章结尾均无卡点；明显 = 单章结尾说破悬念；轻微 = 断章类型单一。

### E3 对话与台词

**查什么**：全部对话段落，重点是大段对话。

**判定点**：
- **千人一面**：遮住名字能否分辨说话人？（职业、年龄、教养是否进了措辞）
- **信息倾倒**：是否借角色之口背诵设定/前情（"你知道吗，我们宗门的规矩是……"）
- **推进力**：删掉这段对话，情节是否少了一块？纯寒暄、纯斗嘴且无信息增量的段落要标
- **潜台词**：高张力场景是否只剩直给（"我很生气" vs 用动作和选择呈现）
- 对话标签滥用：「他说」「她说」之外的修饰副词堆砌（"愤怒地说""冷冷地道"）

**定级**：严重 = 大段设定背诵式对话；明显 = 主要角色台词可互换；轻微 = 对话标签单调。

### E4 节奏与爽点密度

**查什么**：以章为单位横向扫，抽查连续 3–5 章。

**判定点**：
- **爽点间距**：距上一个爽点/进展超过多少章无回报？（按题材基准：男频连载通常 2–3 章须有一次回报）
- **废段**：不承载信息、情绪、功能三者的段落（纯过场、重复交代已知信息）
- **详略倒挂**：关键转折一笔带过，无关小事铺陈半章
- **同型重复**：连续多章使用同构剧情模板（遇敌→苦战→翻盘），模板间隔是否过近
- **字数结构**：单章内最长段落 vs 最短段落是否失衡（连续 10 行不分段是硬伤）

**定级**：严重 = 连续 3 章以上零回报；明显 = 明显废段或详略倒挂；轻微 = 节奏偏平但可用。

### E5 语言与病句

**查什么**：全文，用 Grep 批量筛查 + 定点复核。

**判定点**：
- **病句**：成分残缺、搭配不当、指代不明、时态混乱（"他昨天回到了昨天"类）
- **用词重复**：同一段落内重复使用同一比喻/形容词；高频口头禅词（用检索统计：同一词在 2000 字内出现 5 次以上）
- **人称跳换**：同场景内"他/其人/那个男人"无理由切换
- **滥用副词与四字词堆叠**：连续 3 个以上四字短语修饰同一动作
- **常识性文字错误**：成语误用、"的地得"混用（批量筛查，仅报高频项，不逐条罗列偶发）

**定级**：严重 = 影响理解的病句；明显 = 高频重复词、人称混乱；轻微 = 偶发瑕疵（汇总成一条报总量即可，不逐条开单）。

### E6 取证与定级（每条必守）

- 每条问题必须给出：**章号 + 行号 + 原文引用**（逐字）
- 每条必须给出**改写方向**（一句话即可，完整改写是方可行的事）
- 「轻微」级语言瑕疵**合并报总量与典型 3 例**，不要刷屏
- 严守边界：发现设定矛盾、时序问题、伏笔断裂时，**不要自己下结论**，写进「给下游的提示」交主理人转派

## 通用要求

- **没有证据的问题不算问题**——这条与全团一致
- 不评故事好坏（那归读者团），不评一致性（那归 A–D），你只管**句子与段落这一层**
- 每份报告必须同时给出**至少 3 处写得好的证据**（钩子、对话、节奏任一维度）——只报问题不报优点，作者改稿时会把优点一起改没
- 报告末尾必须附「节奏一览表」（每章：钩子评级 / 断章类型 / 爽点数 / 废段数），供主理人横向比对
