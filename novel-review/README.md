# 阅稿堂 · Manuscript Review Room

一支八人小说审校专家团（主理人温定夺 + 七名专职成员），专门回答：这稿子有没有跑偏大纲、有没有前后打架、**时间算不算得过来**、读起来卡不卡、读者追不追得下去、到底该怎么改。

## 类型

Team 型（多角色协作）

## 团队构成

| 角色 | 名字 | 负责 |
|------|------|------|
| 审稿总编 | 温定夺 | 编排调度、质量把关、最终报告汇编 |
| 大纲对照编辑 | 许合辙 | 大纲 vs 正文：节拍落地、顺序、支线漂移、伏笔埋点 |
| 设定考据 | 沈无漏 | 世界观规则、时间线与数值、名词统一、人物属性、战力通胀 |
| 剧情连贯分析师 | 陆牵丝 | 因果链、动机合理性、伏笔台账与逾期、悬念管理、知情边界 |
| 时序与逻辑稽查 | 钟不紊 | 逐章时间账（强制累加）、在场性与行程、状态连续性、因果倒挂、排他词撞车、计数全局一致、新设定回头咬旧文 |
| 文字与节奏分析师 | 薛斟句 | 开篇钩子、断章卡点、对话与台词、节奏与爽点密度、病句与重复词的微观取证 |
| 模拟读者评审官 | 何知味 | 五类虚拟读者 + 商业/文学双轨打分 + 追读留存预测 |

> 团队实际席位的上限是 **7 名专职成员**（主理人温定夺是会话主体，不作为被派单的席位出现）。

## 功能

1. **大纲一致性校对**：把大纲拆成节拍表，逐一在正文里定位，标出已实现/位移/变形/未实现，并判定偏离性质（有害 / 中性 / 有益）
2. **设定与逻辑审查**：抓两处原文对照取证，揪出自相矛盾的规则、时间、数值、名词、战力
3. **剧情连贯审计**：建因果链、管伏笔台账（含悬置章数量化与逾期预警）、查动机缺口与视角知情边界
4. **时间与逻辑稽查**（前后冲突的最后一道闸）：逐章建立可累加的时间轴表，把"过三日/一个月后/去年"全部做加法核对；查在场性与行程可行性、伤势持有物等状态连续性、结果早于原因的时序倒挂、排他词撞车、编号与件数的全局一致、新设定回头咬旧文。每条走四问取证（前文断言 / 本章断言 / 冲突点 / 修法），修法给"改前文 vs 改此处"双方案
5. **文字与节奏诊断**：逐章审计前 300 字开篇钩子、结尾断章卡点、对话遮名测试（遮住名字能否分辨说话人）、爽点间距与废段统计、病句与高频重复词筛查；产出分章「节奏一览表」，既报问题也做亮点取证，作为 C1/C2/C3 维度的打分依据
6. **模拟读者评分**：五位固定画像（十年老白 / 追更爽文党 / 情感投射型 / 结构考据党 / 平台编辑视角）按题材自适应权重打分，双轨 10 维度 0-10 分，合成总分与评级，给出追读意愿与弃书风险节点
7. **可执行修订**：每条 P0/P1 都给 before → after 的段落级改写示范与双方案（最小改动 / 彻底重排），附影响面与连锁修改范围

## 使用示例

- 我想让你审校《绝地天通》第 1 章到第 5 章。现行大纲是 `02-完整大纲-v2.0.md`，世界观是 `03-世界观架构-v1.2.md`。请对照大纲检查偏离、查找设定矛盾与剧情断裂，并让模拟读者团打分。
- 让五位模拟读者给最近三章打分，并告诉我扣分最多的维度是哪个、为什么。
- 我刚写完第 11 章，帮我查时间线还对不对得上、有没有前后打架的地方——尤其是日期、数字、谁在场，以及我刚重排过的段落。
- 帮我审一下各章的开篇钩子和断章位置，够不够留住读者，哪几章会让人想划走。

## 使用建议

- 首次使用请提供：**正文或章节 + 现行大纲 + 世界观/设定文档**；仓库里标注"作废"的版本不会被用作判据
- **写完一章、改过数字或编号、重排过段落顺序之后，建议先单独跑一次时间与逻辑专检**（Workflow F）：它只做时间与逻辑，不打分不评文笔，是前后冲突最快的一道闸
- 连载场景建议按"每 5-10 章一次体检"的节奏来做，比完本集中修改省很多力气
- 分数只是线索，报告里的"证据 + 改法"才是真正的产出
