## 方向修正：「修内与修外」——两派分野（大纲升 v2.6 / 世界观升 v1.7）

- **作者定案：仙修内，主角阵营修外。**
  - 修内＝吸进体内存储、用体内存的那一份、**用完再吸**；阶名**两字格**：练气 → 筑基 → 金丹 → 元婴。
  - 修外＝**不存**，直接调动外在灵气做功、做完就地散回；阶名**四字格**：炼精化气 → 炼气化神（高阶建议炼神还虚／炼虚合道，待拍板）。
- **区别钉死为"这口气过不过身体"**：进身体就出不来（仙＝死账）；不进身体只是借过（修外＝流水账）。v1.6 那句"修士引入体内做功后散回"是修内的说法，**已改**。
- **阶名的方向就是两派分野**（最好用的一句）：修内越往后越实（气→基→丹→婴，往身上加）；修外越往后越虚（精→气→神→虚→道，往身上减）。→ "加到最后你就是那一颗丹，减到最后我什么也不是。"
- **本条一次性解决了四件悬着的事**：
  1. **反向成长第一次有物理原因**：姜烬是修外者，他要调的那份正是被自己的阵挡住的那份 → **阵越满他越弱**，不是代价是同一动作的两面。
  2. **仙杀他不是报仇是抢路**：修内靠存量，大阵一起再无进项、只出不进；杀阵眼＝上行恢复＝又能吸。"只蛊惑不亲自打"也由此成立——**他们打不起了**。
  3. **"杀光仙也没用"落地**：**仙死存的那份不还**（烧过的炭不能再烧）。若写"杀仙＝灵气回归"，等于开出"杀光仙即复苏"的捷径，根基塌。
  4. **卷六 3-5 亿年有依据**：不是他空等，是**仙的存量要几亿年才花完**。
- **末法成因落到具体处**：天地间能被吸的气，一代代被修内者搬进自己体内锁死——**不是被消耗，是从循环里永久退场**。仙搬走的那车料，搬到他自己肚子里去了。
- **"为什么连自己这条路也要断"新增最硬一层**：修外者用完散回天地的那份，正是仙下一息要吸的 → **不断修外就断不了仙**。埋线：闭关数月出关，那座山灵脉反被仙抽得更狠。
- 连带新设定：**修外无神位**（体内空空，无处挂编制收不上税，所以仙庭一路淘汰古法）；修外正面打不过修内的三条对比（无存量／怕天地没气／死了什么都不欠）。

- **作者对修外的细化（推翻我上一轮的写法）**：
  - **修外＝向内求，修的是精神（灵魂境界）**，以精神**撬动"精神范围之内"的天地灵气**；精神层面越高，撬动越多、威力越大。不是"直接调动"这么简单。
  - **修内＝直接消耗体内存储的灵气**，威力与**法术熟练度、肉身承受度**挂钩。
  - 两派威力公式：修内＝**存量 × 法术熟练度 × 肉身承受度**；修外＝**精神境界 × 灵气浓度**。
- **马达模型（本轮最实用的一处）**：大阵起来后的衰减**是循序渐进、不是一刀切**——电（灵气）足则满转速、效果最好；电少则慢转。
  - 修外者：**立刻变慢**——灵气越稀薄，精神范围内能撬动的越少，还是那一招打出去却轻了。
  - 修内者：**慢慢变少**——存量照旧能打，但消耗掉的补不回来，外界越稀薄越难补充。
  - 由此卷四掉头／卷五暴跌／卷六归零＝马达转速往下掉的三段，**后段终于有坡度可写**。
- **砍掉"修外者用完散回的气被仙吸走／每调一次就是替仙备料"**（作者定案）。它与"大阵不储能、当息散回"不自洽。
  - 替代论证：**两派共用同一片天地**——仙要吸的那份和修外要撬的那份是同一片气，**断仙必断己**。
  - 连带的实证埋线也换掉：原"闭关数月出关见灵脉反被抽更狠"作废 → 改为"**最强的修外前辈晚年占着一座灵山不让任何人靠近**"（修外走到高处要的也是独占一份天地）。
- 名字易误读，口径句：**修"内"修的是体内的灵气存量，修"外"修的是体内的精神境界——两派都向内求，区别只在那口气象谁借。**
- 同步位置：`03` 摘要第 1/2/4/5 条改写 + 新增第 8 条（马达模型）+ 五节主表加"修的是什么／威力由什么决定"两行 + 新增"马达模型"小节 + 强弱对比改（打不了持久战／伤的是精神）+ 七节两处改写 + 八节补充"越难补充" + 禁区新增 2 条、废弃 1 条；`02` v2.6 块全改 + 三节渐进改写 + 规则三表格改 + 埋线替换 + 风险清单 4 条；`04` 追加"回执补充 v1.7 修订"并给旧引文加注。
- 长期教训（第四条）：**给机制找比喻时，先确认它是"渐变"还是"突变"。** 我上一轮写的"天地一锁立刻归零"是突变，会让卷四卷五整整两卷没有坡度——作者用"马达：电少转得慢"一句话救回了整条衰减曲线。凡是跨卷的力量变化，默认按渐变设计。
- 长期教训（第五条）：**我补的"额外因果"要先自查是否与已有定案自洽。** "备料论"与 R-01 的"当息做功、当息散回"直接冲突——散回人间的气被仙吸走，等于上行没断。这类"看起来更狠"的加料最容易破坏地基。
