# 项目长期记忆：《绝地天通》小说创作

## 一、作者硬性约定

- **（2026-09-29 船长定）写完剧情必须前后对照，不得冲突，不得有明显逻辑漏洞。**
  这不是可选步骤，是**每次写完一段/一章后的固定收尾动作**：先自检、再交付；自检结果要报给作者，不藏。
- 改动优先「最小改动」：能位移、能改一句，就不重写整段；作者没要求的地方不动。
- 不代作者决策：新设定、新台词可以给方案并标注推荐项，改不改由作者定。

## 二、一致性自检清单（写完必跑）

七维逐项比对，**只报问题不擅自改**（除非是作者明确指出的硬伤）：

| 维度 | 自查什么 |
|---|---|
| 人物 | 同一人前后称呼、身份、年龄、是否还活着；人名没写串 |
| 时间 | 绝对时间（第几日、几年后）与相对时间（**明天/明年/三天后**）是否还成立 |
| 地点 | 场景方位、距离、谁能在场 |
| 伏笔 | 新埋的线有没有出处；旧伏笔有没有被无意兑现或作废 |
| 因果 | 每个「所以/因此」的因还在不在；新增情节有没有盖掉旧动机 |
| 语气 |  narrator 口径统一（本书禁用现代词、禁用解释性旁白） |
| 事实 | 数字、编号、器物、阶名、规则前后一致 |

**本项目高频雷区（每次都要单独过一遍）：**

1. **排他词撞车**：用「唯一／只有／第一个」制造稀缺时，先查上一句是不是已经承认「这类人不少」。
   解法：换维度排他（人数 → 方向、被动 → 主动）。→ 见 2026-09-29 R-19
2. **相对时间失效**：重排段落顺序后，「明天/三天后/去年」的参照点全部失效，必须重算。
   → 见 2026-09-28 R-16（卯时被误读为第二天）
3. **新设定回头咬旧文**：新增一条设定（如「开漏：只量十三岁」），必须把全书相关人名、事件、数字用新设定筛一遍；旧稿里被当作「先例」引用的人物最危险。
   → 见 2026-09-28 R-17（刘家媳妇被写成测灵出身）
4. **数字与编号**：编号（如涸泽编号、刻痕道数）、年龄、出息数、器物件数，改动后要全局替换，不能只改一处。
5. **抽象区别要落到载体**：定「两派区别」这类设定时，定在载体层面（气过不过身体）比定在抽象层面（取什么/往哪儿去）更不容易漂。
6. **机制要分清渐变还是突变**：跨卷的力量变化默认按渐变设计，突变会抹平整条曲线。
   → 见 2026-09-24「马达模型」
7. **不自洽的「加料」不要写**：看起来更狠的额外因果，常与已定案机制冲突（如「备料论」撞「当息散回」）。先自查再落笔。
8. **年龄链必须闭合**：写「现在几岁 + 进来/走了几年」时，两者相减必须等于「那年几岁」，同段里若还有「比你大几岁」也要一起验。加厚时新写的人物台词最容易在这里破。
   → 见 2026-09-29 R-22（崔姐「进来那年十一」与「比你大九岁」差两岁）
9. **加厚≠注水**：补字数时只加三类东西——感官与体感、次要人物的一两句、机制的可见面（不解说）。补完必须重跑一遍互锁数字验算，因为新写的对话一定会引入新数字。
   → 见 2026-09-29 第 11-20 章加厚（四轮，新增 17 条硬设定，同时抓出 4 处硬伤）
10. **重锤必须回收，且「埋因在前、收果在后」**：凡是册子上的字、编号、一句判词这类揭示，落笔前先查全书有没有回收点——**只出现一次＝白砸**。标准打法：前章只给「音/动作/画面」，后章（隔 5-10 章）才让他自己看见「形/结论」。
   → 见 2026-09-30 M-20：「父、母，亡」原本只在第 1 章出现一次、全书无回收 → 改为第 1 章给音、第 11 章在册纸上撞见字形并破解「亡和转是一起的」。
11. **作者标斜体/脚注改稿时，先 grep 全文锁定互锁点再动笔**：一处改动牵动几章，grep 一次就清楚；只改标出来的那一处必漏。
   → 见 2026-09-30：木牌改一处 → 牵动第 3/10/16/19 章 ＋ 正文附录 ＋ 时间轴台账；「亡」字挪位 → grep 抓出第 2 章已提前剧透字形、第 6 章已写「他认得亡字」的冲突（两处都是改前没暴露、改后才炸的）。

## 三、已成文的硬设定（写新章前对照，防止吃书）

- **两派**：仙＝**修内**（吸进体内存着，两字格：练气/筑基/金丹/元婴）；主角阵营＝**修外**（不存，修精神境界，以精神撬动外在灵气，四字格：炼精化气/炼气化神）。两派阶名不许混写。
  - ⚠️ **修外的定义（2026-10-13 作者裁定）**：修外＝**不走吸收到体内这条路**（方法选择），落地为「不装不存、只借（伸／够／还）」。**绝非「天生存不住气」那种天生缺陷**——那是姜烬个人的「气活」批语（气不往体内存），与修外这条路同构，所以他是天然的修外候选，但修外本身是方法，不是缺陷。仙门按修内「存住才算真上品」的尺子误读他为缺陷，正是 ch2「上品却发外舍」那场错位的来源。写新章时严禁把修外定义回「天生存不住／气过身不留」的旧口径。
- **开漏**：人身上的气十三岁才开始外冒，只量**十三十四十五**这一茬；十五六后漏一分补一分，灵鉴称不出。白榆门**三年下乡一回**。
- ⚠️ **气活 ≠ 开漏（作者裁定，2026-10-13 钉死）**：开漏＝13-15 岁人人暂有的「装不住」（测灵窗口本身）；气活＝姜烬个人永久的「进不了身」（册批二字，与修外同构）。⚠️ **时序更正（2026-10-13 二次裁定·作者拍板）**：灵鉴只量外泄净值→上品是「漏得多、气旺」，与「装不装得进」是两回事；山门口根本无从诊断气活，若 picker 当场黜「装不住」＝未卜先知、逻辑崩。故 ch2 已重排——**真上品先进内门，修内「往里装」装不进→册批气活→改派外舍**；气活诊断权归**内门教习**，山门口不再出现。ch9 开漏段仍由姜烬回收「他的气活不是开漏」。严禁再把气活诊断塞回山门口／picker，也严禁写「姜烬一上山就是外舍」——他先内门后改派。
- **大人走征仙役，孩子走测灵**——两本册子一个去处。成年人不可能被测过灵。
- **仙不碰人**：仙只消耗/提纯灵气，不索取众生任何东西。**仙死，存的那份不还。**
- **命如屋**：寿元不归任何一家独有，四家各拆一部分（妖砖木气血／佛屋脊信仰／魔门窗怨念／仙搬补墙的泥）。
- **补齐**：少一份就摊到所有人头上（改良无用的肉身版）。
- **降罚必须伪装成天灾。**
- **姜烬不哭**（不是忍着，是「没资格难过」）；村里人被带走一律叫「**走**」，禁用「抱走」。
- 刘家媳妇＝「走的时候孩子才刚会爬」，走的是征役；她男人是**自己走上去要人**的那一个，下来半个月就死了，临死说「他们没让我见着她」。
- **姜烬的木牌（2026-09-30 重定）**：规矩＝**只刻亲眼看着没了的人**——「走的时候不刻，要等看见」。第 1 章削好时**是空的**（心里记着二十七个）；姜萤那一道**不刻**（她是被「取」走的，不是「没了」）；**第一道＝老蔺（第 10 章天火）**；第 16 章在崔姐门口没刻第二道；第 19 章姚庆看时仍只有一道。旧链「28（姜萤）→29（老蔺）」作废。

### 4. 工程教训

- **长文本写入会混入英文噪音**（本轮 6 处）。中英混排正则 `[\x{4e00}-\x{9fff}][A-Za-z]{2,}[\x{4e00}-\x{9fff}]` **抓不到空格分隔的情况**——必须用 `[A-Za-z]{2,}` 全扫，再过滤表格行与 `.md` 文件名。
- **动笔前先 grep 你以为"还没交代"的信息**。第 21 章差点把甘伯早就说过的"每月十六"写成主角推算，重复一次就贬值一次。
