## 第二轮修订：跨纪元架构 + 角色体系（v0.2）

- 作者追加构想：主角靠阵法长生到现代，世界像地球史一样演进（寒武纪→泥盆纪→白垩纪→现代）。
- 采纳并落地为"一卷 = 一个纪元"：
  卷一荒古（吞噬血肉）／卷二远古（立庙收香火）／卷三上古（扶植王权、战争收割）／卷四中古（宗门纪，把掠夺包装成修行）／卷五近古（枯竭纪，同类相食）／卷六现代（末法）。
- 关键纵深：**掠夺的本质从未变，变的只是手续费**——收割手段随文明升级。
- 跨纪元最大风险是读者感情清零，定下三根钉子：贯穿型角色、血脉接力（守薪人，每纪元同一血脉的后人）、告别仪式（每纪元末固定三拍）。
- 角色体系：贯穿线＝血脉传承者 + 长生对手（每纪元来杀一次，一次比一次虚弱，最后其实在等主角成功）；纪元线每纪元 2-3 人，已设计荒古石/巫、远古庙祝/断舌、上古女将/史官、中古大师兄/炉鼎七十三/窃火者、近古末代掌门/食人者、现代床边人。

## 第三轮修订：牺牲机制与奉献主题落地（v0.3）

作者诉求：在断绝修行路的过程中体现自我奉献、牺牲小我成就大我。

落地方案（已写入大纲第八节）：
- **自愿做成机制条件**：被迫的愿力会被污染，大阵只接受主动交出修为的人。奉献从说教变硬门槛，主角只能一个一个说服。
- **四层代价递进**：众生（不知情被抽愿力）→ 入阵者（知情自愿，交出修为寿元记忆）→ 主角（修为归零、困于阵眼、目送所有人老死）→ 被遗忘（无人记得他做过什么）。
- **最重磅的一笔：主角牺牲的是"被记住的权利"**。与楔子闭环——现代医院医生问"家属呢"，没人回答，不只是悬疑，是他真的什么人都不剩了。
- **主角态度三段转变**：拒绝（"我不会让任何人替我去死"）→ 被迫接受（第一次开口说服某人入阵，写开口前的沉默）→ 自己入阵（成为最后一个）。不写这个，主角会变冷酷棋手。
- **入阵者名录**：名字刻木牌，刻满换一块。卷六现代线下落建议：当柴烧了，或躺在博物馆角落标"不详用途的木质器物"。
- **必须保留反对者视角**：由卷四大师兄提出"你凭什么决定断绝修行？修行是很多人活下去的唯一指望"，主角无法完美反驳。
- 三条禁令：禁止牺牲竞赛、禁止牺牲后立刻变好、禁止主角道德完人。

## 第四轮修订：结尾一次性揭示，取消抢救室闪回（v0.4）

作者决定：不要抢救室闪回规则，要在结尾让读者恍然大悟"原来这是主角临终前的回忆"。

落地方案（已写入大纲第五节与相关各处）：
- **取消闪回与楔子**。开篇直接进荒古，无任何现代元素。
- **现代只在终章出现一次**。正文五卷走完荒古→近古，卷六收束大阵平衡（正文到此为止），终章硬切现代医院揭示。现代场景提前露面一次，反转就废。
- **伏笔改为"叙述裂缝"**：全书第三人称，偶尔插入追忆口吻句（如"那一年我十三岁，我见过很多个十三岁的人"）。关键洞察——**主角本来就长生，所以老人口吻毫无违和，是天然保护色**，读者不会提前猜到。密度每卷 2-3 处，全书≤15 处。
- **揭示时的五处含义翻转**：「我活了很久」= 快死的人的疲惫；每纪元告别 = 他在清点送走的人；木牌刻名 = 确认自己没忘掉谁；「后来我再没见过他」= 真的再没见过；全书记得细 = 将死之人怕忘。核心立意：**整本书是一个将死之人拼命想要记住自己一生的努力**。
- 代价已认下并写入风险清单：去掉闪回＝抽掉百万字贯穿暗线，中段牵引变弱，靠大阵进度条 + 告别仪式 + 叙述裂缝三者补。
- 双结局与揭示不冲突：他确实走到临终那一刻，回忆完了，心跳可能回来（甲）也可能不（乙）。
- 文件更新为 v0.4：`20260923-绝地天通/01-大纲与开篇设计.md`。

## 第五轮修订：卷首语机制（v0.5）

作者决定：叙述裂缝固定放在每卷开头，作为卷首语，之后展开该卷正文。

- 定案：每卷开头一段 100-200 字卷首语，追忆口吻，只定情绪不预告剧情。固定位置形成仪式感，揭示后回看才有力量。
- **核心要求：六段卷首语连起来 = 一个人从少年到临终的心境史**。主题字与心境：卷一名（少年·愤怒）、卷二偷（窃火·得意）、卷三盟（结盟·热血）、卷四门（断绝·决绝）、卷五送（送别·苍凉）、卷六忘（遗忘·释然）。
- 六段口吻示范已写入大纲（可改）。**卷六"我记得的不多了"是全书的钥匙**——首读以为是长生者的自嘲，揭示后才知道他是快死了在拼命想。
- 三条硬规矩：只定情绪不预告剧情；全篇不出现现代元素；六段开头句式不能一样（否则机械感会让读者追究说话的人是谁）。
- 文件更新为 v0.5：`20260923-绝地天通/01-大纲与开篇设计.md`。

## 第六轮修订：规则一二定案 + 去掉新型爽点 + 反复苏战（v0.6）

作者三项改动：

   - 卷四末必须明确告诉读者：此后主角是棋手与说客，不是战士。

2. **规则一定案**：众神不能亲自下界，两层限制——(a) 众神有阵营互相制衡，谁也不敢先动；(b) 插手人道沾染业力、消减道行（类封神人道压制）。
   - 三个关键推论：仙门＝众神在人间的白手套；互相牵制给了主角操作空间；**主角核心计谋＝利用众神阵营矛盾借力打力**。

3. **规则二定案**：长生代价＝大阵笼罩整个世界（宇宙），看着所有人死（亲友、弟子、甚至敌人）。配套：卷五卷六用计谋 + 当世之人破坏仙神复苏阴谋。

新增**卷五卷六轮回结构（反复苏战）**：仙神出手 → 主角识破 → 找当世之人 → 布局破坏 → 送走一批人 → 下一轮。撑得起百万字后段，且每轮自然生成告别戏。
五类复苏手段与破解已列表（代理人／挑动内斗／造新信仰／找漏洞／等他死）。最后一招最狠：两个都在等，看谁先撑不住——这是全书终局底色。

## 第七轮修订：两条贯穿线重设（v0.7）

**贯穿线一 → 守薪人 = 前人反抗者的后人**（作者定案）
- 在主角之前反抗仙神且失败的那批人的后裔。守的不是秘密，是上一次反抗没烧完的那点火。
- 每纪元的后人暗中保存火种、记录情报；**卷四大阵成型时拿出全部积累提供关键助力**；成型后血脉散入凡人、不再传承 → 末代后人即终章"床边那个人"，已不知自己血脉的意义。
- 关键：祖先是失败者，主角不是第一个想做这件事的人，只是第一个做成的。
- 固定台词"我祖父临死前说，你会回来"保留，但重量变了：不是预言，是失败者留给后人的交代。

**贯穿线二 → 仙神的代言人（"薪柴"）**（作者定案）
- 大阵形成前与主角对线，最后发现自己也是薪柴，反水、对抗仙神、死亡。
- 我方机制设计：仙神赐他长生作为报酬，**但那长生是贷款**——每动用一次力量就烧掉一分自己，越忠诚烧得越快。他不是工具，是燃料。
- 主题价值：仙神收割众生连自己人也吃，这是全书主题的最小缩影。反水动机是"发现自己也被烧"，比良心发现硬。
- 四段弧：受命得长生 → 与主角对线（每战一场少活一分）→ 发现自己被烧 → 反水烧尽。
- **死亡建议放在卷四**：用最后一点力量助主角成阵，主动把燃烧的自己投入大阵 = 全书最重的奉献戏（与"自愿入阵"机制咬合）。
- 代价：他死后卷五卷六主角再无对话对手 → 主角彻底孤独，这本就是长生代价的一部分。后段对手改为每轮换新的仙神代理人。
- 风险已记：反水不能突兀，从卷一起铺"燃烧"痕迹（出手后要歇很久、身上有焦味、从不在同一处久留）。

## 第九轮修订：守薪人灭绝 + 卷五大灭绝五幕 + 卷六叙事体（v0.9）

作者定案：

1. **守薪人台词最终定稿：「我们等了很久。久到已经没人记得在等什么了。」**
   - 上版"别让火灭了，他没说等谁"降级为备选/变体。定稿句主语是"我们"（群体在守），"没人记得在等什么"把绝望推到顶。
   - 这句在**卷四大阵成型、交接全部积累时**说出，是全书最重的一次交接。

2. **守薪人灭绝（推翻 v0.8 的"融入火种"）**：他们知道太多、修得太深、与灵气绑太紧 → 灵气一断就活不成。火传下去了，守火的人一个没剩。
   - **连带作废**：原"末代后人＝终章床边那个人"。守薪人既灭绝，**终章床边改为无人**。医生问"家属呢"，没人回答。
   - 终章最后一笔：护士掰开他的手，取出一小块碳化的木头（木牌残片），看不出是什么，放进废弃物袋。**不解释它是什么。**

3. **火种定案＝一群还没有踏入修行的普通人**。断绝修行要断得彻底，不留后门：守薪人、仙门、灵兽一个不留。

4. **卷五重构为五幕**：断（全宇宙修行者灭绝，只剩该星球的主角与火种）→ 眠（守薪人灭绝，主角首次沉睡）→ 兽（仙神后手：部分灵兽发狂为嗜杀野兽，剩余灵兽与人类结盟抗兽）→ 退（人兽一同退化，野兽占据星球）→ 劫（陨石坠落，环境剧变，旧世界清零）。
   - **仙神后手的价值**：烙印埋在灵兽血肉里，灵气断绝则发狂。野兽无灵智→无法产生愿力→**仙神亲手毁掉最后一点可收割的资粮**。这不是阴谋，是泄愤，说明他们已经输了只剩恨。

5. **卷六改为叙事体编年**（陨石后 → 史前 → 部落 → 立国 → 国家争斗 → 现代 → 抢救室）。
   - 防流水账：**锚点 + 压缩**——挑 8-12 个关键事件写成具名场景（2000-4000 字），锚点之间用叙事体几段带过。已列 10 个锚点候选（走出山洞／第一次取火／兽群最后一次围攻／第一个王／第一次写下字／一个人的疯狂／有人问"神仙在哪"／一场不该发生的战争／铁与火的时代／最后一次被人认出）。
   - 第 7 个锚点是主题兑现点：人类不再信神仙，不是因为被说服，是因为真的没有神仙了。

6. **新增主角沉睡机制**：周期性苏醒，间隔越来越长、清醒越来越短，全书不超过 5 次。

6. **最狠的一处：魔是仙佛养的。** 魔吃恐惧，而恐惧是香火最好的肥料；仙佛从不禁魔，只是"表演镇压"。由此给卷三末"杀不完"补上硬逻辑：**杀一个魔 → 恐惧减弱 → 香火变淡 → 仙庭立刻扶新的**。他杀得越狠他们补得越快。
7. **修士的管道化**：高阶之后体内存不住，吸多少就得持续再吸多少，否则掉阶 → 解释了仙神停不下来、必须扩张、以及断供后自己消亡（**不是被杀，是断粮**）。神位＝编制，断供即崩，可被褫夺。
8. **飞升的真相**：接引不是接引，是**收款**。
9. **末法景象**：诸天不是被隔绝，是**庙空了、灯灭了**；神像还在，香炉冷了，然后神自己散了。
10. **"永远不能停"的机制解释**：只要众生还在起念，灵机就在生成 → 只要有人活着他就得一直吸。这是他的岗位说明书。
11. 修行资源清单八类（灵脉/香火池/秘境/丹器符/功法/寿元册/神位碑/修为本身）、生灵谱系七类（凡人/妖/魔/鬼/龙/散修/炉鼎祭品）、境界九阶（层级恒定、称呼随纪元变）。

## 第二十一轮：v2.1 —— 卷六三项定案 + 主角出身改判

### 三项作者定案

1. **卷六时间尺度＝甲（地质写实，约 3-5 亿年）。** 正文不点破具体年数，只给"很久""记不清是第几次醒来"——写出来读者会开始算，不写才是敬畏。
2. **陨石后的环境骤变灭绝了所有人（含火种）。** 他第 4 次醒来，一个人都没有。**他守住了星球，没守住上面的任何人。**
   → 之后他教化演化出的类人生物（猿类），现代人类是他教出来的。**他没有造人，只是让这一步早来了很久**，符合人类进化学说。
   → **他教完必须走**：有人跪他那一刻，他就成了他反对的东西。教完就走是"不想有人跪"唯一的兑现方式。
   → 由此第四层代价升到顶点：**不是别人忘了他，是他的学生不知道有过老师。**
3. **姜烬与姜萤不是亲兄妹**，是同村孤儿，父母被掳走（疑似魔门／妖魔）。**他参加测灵的动机是打听父母下落——他是半自愿走进去的。**

### 由第 3 项打通的关键链条（本轮最有价值的一处）

**登记 → 编号 → 炉鼎七十三**

- 第 1 章：全村道贺，仙门上门"登记全家"。第一章要读者懂的一句话：**资质不是运气，是被登记入库。**
- **第 2 章改写为"登记之后，是编号"**：他上山打听父母，被引到一处栏笼群——**里面的人没有名字，只有编号**，正在被抽干。他没找到父母，只在某一号栏笼里看见一件认得的遗物。**没有答案，只有遗物。**
- 卷四：他会再遇到一个编号的人——**炉鼎七十三**。读者自己会算过来：第 2 章路过的那一排里，七十三号也许就在那儿。
- 父母的下落吊到卷三甚至永不了结。若给答案，最狠写法：**他找到了，但他们已经认不出他了。**

### 其他连带修订

- **蛊惑线在卷六中期是断的**：火种全灭后可蛊惑的对象也没了。等到新智慧生物起来才接上——**正是因为空了很久，它重新响起来才吓人**。复现顺序：先蛊惑兽（巨兽之世），很久之后才蛊惑人。
- **沉睡改为 8 次**，节点绑定"世界换了模样"的时刻。第 4 次（火种全灭）与第 7 次（教火）是两个情感顶点。第 8 次醒来后不再睡。
